# Suggested Study Plan

A 2.5-week plan, ~45–60 min/day.

## Week 1 — Layout fundamentals

- Day 1–2: `01-selectors-specificity`
- Day 3–4: `02-box-model-layout` (margin collapsing especially — spend extra time)
- Day 5–6: `03-flexbox` (the `flex-shrink` weighted-math trap is the #1 thing candidates get wrong)
- Day 7: `04-grid` (`auto-fill` vs `auto-fit` — memorize the worked examples)

## Week 2 — Positioning, responsiveness & modern CSS

- Day 1–2: `05-positioning-stacking` (stacking contexts — the "why does z-index:9999 lose" trap)
- Day 3: `06-responsive-design-media-queries`
- Day 4: `07-css-variables-custom-properties`
- Day 5: `08-animations-transitions`
- Day 6–7: Review — `output-based/` for topics 1–8

## Week 2.5 — Selectors, architecture & modern features

- Day 1: `09-pseudo-classes-elements`
- Day 2: `10-css-architecture-methodologies`
- Day 3: `11-modern-css-features`
- Day 4: Full review — every `interview-qa/` folder, timed self-quiz

## Interview-week fast pass

1. `output-based/` for `03-flexbox`, `04-grid`, `05-positioning-stacking` — this is where interviews actually
   probe (computed sizes, stacking order)
2. `scenarios/` for `01-selectors-specificity`, `02-box-model-layout`, `06-responsive-design-media-queries`
3. Comparison tables inside `theory/` across the repo (flexbox vs grid, transition vs animation, BEM vs
   utility-first)
4. `problems/` if you have time — "build X from scratch" (a sticky header, a responsive card grid, a
   specificity-safe component) comes up constantly in CSS interviews
