Both `a` and `b` evaluate to **`true`**:

```text
a = true
b = true

```

---

### Why this happens

`Array.prototype.every()` checks whether **all** elements in the array pass the test implemented by the callback function.

* **Vacuous Truth (Empty Array Rule):** For an empty array `[]`, there are no elements to test. Since there is no element that fails the condition (returns a falsy value), JavaScript considers the condition satisfied and immediately returns **`true`**.
* The callback function `() => false` is **never executed** because the array has a `length` of `0`.

---

### Comparison with `some()`

| Method              | Behavior on `[]` | Reason                              |
| ------------------- | ---------------- | ----------------------------------- |
| **`[].every(...)`** | **`true`**       | No element failed the predicate.    |
| **`[].some(...)`**  | **`false`**      | No element succeeded the predicate. |
