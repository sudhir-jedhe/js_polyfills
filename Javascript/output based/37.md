What happens depends on whether your JavaScript is running in **Sloppy Mode** (default) or **Strict Mode** (`"use strict"`):

### 1. In Sloppy Mode (Default)

It executes without an error, but the duplicate parameter name overrides the earlier one:

```js
function test(a, a) {
  console.log(a);
}

test(10); 
// Output: undefined

```

* **Why it prints `undefined`:** JavaScript assigns arguments by position. The first parameter `a` gets `10`, but the second parameter `a` (which shares the same variable name and overwrites the first) receives the second argument—which is missing, so it resolves to `undefined`.
* If you called `test(10, 20)`, `a` would be `20`.

---

### 2. In Strict Mode / ES Modules

It throws a **`SyntaxError`** at parse time:

```js
"use strict";

function test(a, a) {} 
// Uncaught SyntaxError: Duplicate parameter name not allowed in this context

```

Strict mode (as well as ES modules, class methods, and arrow functions with default/rest parameters) forbids duplicate parameter names entirely to prevent accidental shadowing bugs.
