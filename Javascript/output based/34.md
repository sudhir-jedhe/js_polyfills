Here is the step-by-step breakdown of how the object is constructed and what each `console.log` outputs:

### 1. Object Construction

```javascript
const one = "Sagar";

const obj = {
  ["one"]: "Vijay", // Computed string literal -> creates key "one" with value "Vijay"
  [one]: "Ajay",    // Evaluates variable `one` ("Sagar") -> creates key "Sagar" with value "Ajay"
};

```

After initialization, the object in memory looks like:

```javascript
{
  one: "Vijay",
  Sagar: "Ajay"
}

```

---

### 2. Output for Each `console.log`

* **`console.log(obj[one])`** $\rightarrow$ **`"Ajay"`**
* Evaluates the variable `one`, which is `"Sagar"`.
* Looks up `obj["Sagar"]`, which holds `"Ajay"`.

* **`console.log(obj["one"])`** $\rightarrow$ **`"Vijay"`**
* Directly accesses the key `"one"`, which holds `"Vijay"`.

* **`console.log(obj.one)`** $\rightarrow$ **`"Vijay"`**
* Dot notation accesses the literal property name `"one"`, which holds `"Vijay"`.
