* The sub-expression `10 +` is evaluated and held in memory.
* Execution reaches `await 2`. The value `2` is wrapped into a resolved Promise (`Promise.resolve(2)`).
* **`test()` suspends execution** and queues its continuation into the **microtask queue**. Control is yielded back to the synchronous thread.

1. **Synchronous code continues:**

* `x = 0 + 20` executes immediately.
* `x` is now set to **`20`**.
* Synchronous log prints: `Outside test: 20`.

1. **Microtask execution:**

* The call stack is now empty, so the event loop picks up the continuation of `test()`.
* `await 2` resolves to `2`.
* The held addition completes: `10 + 2 = 12`.
* `x` is assigned **`12`** (overwriting the previous value of `20`).
* Inside log prints: `Inside test: 12`.
