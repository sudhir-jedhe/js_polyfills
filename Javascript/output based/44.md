### 9. Shallow Copy via Object Spread (`4.33.51 AM.png`)

```javascript
const obj1 = { name: "Mohit", age: 30 };
const obj2 = { ...obj1 };

obj2.name = "Rahul";

console.log(obj1.name);

```

* **Explanation:** `{ ...obj1 }` creates a new shallow clone. Mutating primitive properties on `obj2` does not affect `obj1`.
* **Output:** `"Mohit"`
