Here is how the code translates in JavaScript:

```javascript
const obj = {
  a: 1,
  c: () => {
    return this.a;
  }
};

// Case 1:
console.log(obj.c());

// Case 2:
console.log(obj.c.call({ a: 1 }));

```

---

### 1. What happens with `console.log(obj.c())`?

* **Result:** `undefined` (in standard browser environments or strict mode).
* **Why:** **Arrow functions do not have their own `this` binding.** Instead, they inherit `this` lexically from the surrounding scope where the object was created (the outer global/module scope).
* At the global level, `this.a` is `undefined` (or points to `window.a`, which does not exist unless explicitly set on `window`).

---

### 2. What happens with `console.log(obj.c.call({ a: 1 }))`?

* **Result:** Still **`undefined`**.
* **Why:** Arrow functions are **lexically bound permanently**. The methods `.call()`, `.apply()`, and `.bind()` **cannot override or rebind `this` on an arrow function**. The first argument passed to `.call(...)` is simply ignored by the arrow function.

---

### Summary Table

| Execution              | Output      | Reason                                                                          |
| ---------------------- | ----------- | ------------------------------------------------------------------------------- |
| `obj.c()`              | `undefined` | Arrow function inherits `this` from outer scope, not `obj`.                     |
| `obj.c.call({ a: 1 })` | `undefined` | `.call()` / `.apply()` / `.bind()` cannot override `this` in an arrow function. |

---

### How to make it return `1`

To allow `this` to point to `obj` (or be rebound via `.call()`), use a **regular function** or standard method syntax:

```javascript
const obj = {
  a: 1,
  c() {
    return this.a;
  }
};

console.log(obj.c());                  // 1
console.log(obj.c.call({ a: 100 }));   // 100

```
