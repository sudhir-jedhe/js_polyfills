```js
console.log(Math.min())
console.log(Math.max())
console.log(Math.min(1))
console.log(Math.max(1,2))
console.log(Math.min([1,2,3]))
```

**Output:**

```javascript
Infinity
-Infinity
1

```

---

### Step-by-Step Breakdown

1. **`Math.min()` $\rightarrow$ `Infinity**`

* With no arguments, `Math.min` starts comparing against its identity value: positive infinity (`Infinity`). Any finite number compared against `Infinity` would be smaller.

1. **`Math.max()` $\rightarrow$ `-Infinity**`

* With no arguments, `Math.max` starts comparing against its identity value: negative infinity (`-Infinity`). Any finite number compared against `-Infinity` would be larger.

1. **`Math.min(1)` $\rightarrow$ `1**`

* Returns the smallest of the provided numbers: `1`.

1. **`Math.max(1, 2)` $\rightarrow$ `2**`

* Compares `1` and `2`, returning the largest: `2`.

1. **`Math.min([1, 2, 3])` $\rightarrow$ `NaN**`

* `Math.min` does not accept arrays directly.
* It coerces its arguments via `Number([1, 2, 3])`.
* `[1, 2, 3].toString()` becomes `"1,2,3"`, and `Number("1,2,3")` evaluates to `NaN`.
* Any comparison involving `NaN` results in `NaN`. *(To pass an array properly, use spread syntax: `Math.min(...[1, 2, 3])`)*.
