### Step-by-Step Breakdown

1. **`const a = [0]; console.log(a.length)` $\rightarrow$ `1**`

* The array starts with a single element `[0]`, so `length` is `1`.

1. **`a[3] = 3; console.log(a.length)` $\rightarrow$ `4**`

* Setting index `3` creates a **sparse array** (`[0, empty × 2, 3]`).
* The length expands automatically to `index + 1 = 4`. Indices `1` and `2` are "empty slots" (holes), not actual keys.

1. **`for (let item of a)`:**

* `for..of` uses the array's iterator protocol, which reads indices by position up to `length`.
* Unassigned/empty slots yield `undefined`.
* Logs:

```javascript
0
undefined
undefined
3

```

1. **`a.map(...)` and `a.forEach(...)`:**

* Array higher-order methods (`map`, `forEach`, `filter`, `reduce`) **skip empty slots entirely**; they only visit existing, initialized indices (`0` and `3`).
* `a.map` logs: `0` and `3`.
* `a.forEach` logs: `0` and `3`.

1. **`console.log(Object.keys(a))` $\rightarrow$ `["0", "3"]**`

* `Object.keys()` returns only an object's own enumerable properties. Empty slots have no keys, so only `["0", "3"]` are returned.

1. **`delete a[3]; console.log(a.length)` $\rightarrow$ `4**`

* The `delete` operator removes the property/value at index `3`, turning it back into an empty slot.
* `delete` **does not mutate `length**`. The length remains `4`.

1. **`a[2] = 2; a.length = 1; console.log(a[0], a[1], a[2])` $\rightarrow$ `0 undefined undefined**`

* `a[2] = 2` populates index `2`.
* Setting `a.length = 1` explicitly **truncates** the array, permanently deleting all elements and slots at index $\ge 1$.
* `a[0]` is `0`.
* `a[1]` and `a[2]` no longer exist, evaluating to `undefined`.
