---

### Step-by-Step Breakdown

**Core Rules (`var` vs. `let` in the Global Environment Record):**

* The global environment record consists of two separate internal components:

1. **Object Environment Record:** Holds declarations created with `var` and `function`. In a standard browser script, this is directly bound to properties on the global object (`window` / `this`).
2. **Declarative Environment Record:** Holds top-level block-scoped declarations created with `let`, `const`, and `class`. These variables are global in scope, but they are **never added as properties** to the global object (`this`).

---

1. **`console.log(this.a)`:**

* In a top-level browser script, `var a = 'BFE'` creates a property `a` on the global object `window` (`this`).
* `this.a` resolves to **`"BFE"`**.

1. **`console.log(this.b)`:**

* `let b = 'bigfrontend'` lives in the declarative environment record and does **not** become a property of `window` (`this`).
* `this.b` checks for an own/prototype property named `b` on the global object, finds none, and evaluates to **`undefined`**.
