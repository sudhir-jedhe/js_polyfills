console.log(Reflect.ownKeys([]))
console.log(Reflect.ownKeys([,]))

console.log(Reflect.ownKeys([...[1,,2]]))



```

**Output:**

["length"]

["0", "1", "2", "length"]

```

---

### Step-by-Step Breakdown

**Core Rules (`Reflect.ownKeys` & Sparse Arrays):**

* `Reflect.ownKeys(target)` returns an array of all own property keys (including non-enumerable properties like `length`), ordered with integer indices first (in ascending numeric order), followed by string keys in insertion order.
* **Sparse Arrays (Holes/Elisions):** Empty slots created via commas (e.g., `[1, , 2]`) do **not** create own property keys for those missing indices.
* **Spread Operator (`...`):** Array spreading relies on the built-in iterator (`Array.prototype[Symbol.iterator]`), which converts empty slots (holes) into explicit `undefined` values, creating actual own properties for those indices in the new array.

---

1. **`Reflect.ownKeys([])` $\rightarrow$ `["length"]**`

* An empty array has no elements, only the built-in non-enumerable own property `"length"`.

1. **`Reflect.ownKeys([,])` $\rightarrow$ `["length"]**`

* The trailing comma defines an array with a single empty slot (`length: 1`), but index `0` is unassigned and not an own property.
* Only `"length"` exists as an own key.

1. **`Reflect.ownKeys([1,,2])` $\rightarrow$ `["0", "2", "length"]**`

* Index `0` (`1`) and index `2` (`2`) are defined own properties.
* Index `1` is a hole (sparse slot) and does not exist on the object.
* Combined with `"length"`, the keys are `["0", "2", "length"]`.

1. **`Reflect.ownKeys([...[1,,2]])` $\rightarrow$ `["0", "1", "2", "length"]**`

* The spread operator iterates through `[1,,2]`, yielding `1`, `undefined`, and `2`.
* The newly constructed array is dense (`[1, undefined, 2]`), having defined own properties at indices `"0"`, `"1"`, and `"2"`.
* Result is `["0", "1", "2", "length"]`.
