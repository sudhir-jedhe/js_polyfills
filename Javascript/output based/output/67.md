### Step-by-Step Breakdown

**Core Rule (Annex B.3.3 — Function Declarations in Block Scope):**

* In non-strict mode, function declarations inside blocks hoist a variable declaration (`var foo`, `var bar`) to the enclosing scope initialized to **`undefined`**.
* The outer variable only receives the function definition when the engine actually enters and executes the corresponding block.

---

1. **`if (true)` block:**

* The condition is truthy, so execution enters the block.
* `foo` is bound to the function definition in the outer scope.
* `foo()` executes successfully and logs: **`"BFE"`**.

1. **`if (false)` block:**

* The condition is falsy, so execution skips the block entirely.
* `bar` remains **`undefined`** in the outer scope.
* Attempting to invoke `bar()` results in calling `undefined()`, which throws:
**`Uncaught TypeError: bar is not a function`**.
