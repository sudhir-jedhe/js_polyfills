```js
async function async1(){
  console.log(1)
  await async2()
  console.log(2)
}

async function async2(){
  console.log(3)
}

console.log(4)

setTimeout(function(){
  console.log(5)
}, 0)

async1()

new Promise(function(resolve){
  console.log(6)
  resolve()
}).then(function(){
  console.log(7)
})

console.log(8)

```

### Step-by-Step Breakdown

1. **Synchronous Execution (Call Stack):**

* `console.log(4)` runs $\rightarrow$ logs **`4`**.
* `setTimeout(..., 0)` registers a timer callback to the **Macrotask Queue**.
* `async1()` is called:
* `console.log(1)` runs $\rightarrow$ logs **`1`**.
* `await async2()` calls `async2()` synchronously:
* `console.log(3)` runs $\rightarrow$ logs **`3`**.
* `async2` returns a resolved promise.

* The `await` suspends `async1` and schedules its continuation (`console.log(2)`) as the **first microtask** in the **Microtask Queue**.

* `new Promise(...)` executes its executor function synchronously:
* `console.log(6)` runs $\rightarrow$ logs **`6`**.
* `resolve()` resolves the promise.

* `.then(...)` registers its callback as the **second microtask** in the **Microtask Queue**.
* `console.log(8)` runs $\rightarrow$ logs **`8`**.

1. **Microtask Queue (Executed before any timer/macrotask):**

* **Microtask 1:** The remainder of `async1()` resumes $\rightarrow$ logs **`2`**.
* **Microtask 2:** The `.then()` callback executes $\rightarrow$ logs **`7`**.

1. **Macrotask Queue:**

* The `setTimeout` callback executes $\rightarrow$ logs **`5`**.
