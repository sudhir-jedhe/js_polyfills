async function a() {
  try {
    return await Promise.reject(1)
  } catch (e) {
    console.log(e)
  }
}

async function b() {
  try {
    return Promise.reject(2)
  } catch (e) {
    console.log(e)
  }
}

async function start() {
  await a()
  await b()
}

start()

**Output:**

```javascript
1
Uncaught (in promise) 2

```

---

**Step-by-Step Breakdown:**

1. **Inside `a()`:**

* `return await Promise.reject(1)` waits for the rejected promise within the `try` block.
* Awaiting the rejected promise throws an exception inside the function body, which is immediately caught by the `catch (e)` block.
* `console.log(e)` executes and logs `1`.
* Function `a()` resolves cleanly with `undefined`.

1. **Inside `b()`:**

* `return Promise.reject(2)` returns a rejected promise **without awaiting it** inside the `try` block.
* Because it is returned without `await`, the `try...catch` block never intercepts the rejection at runtime.
* The returned rejected promise propagates out of function `b()`.

1. **Inside `start()`:**

* `await a()` completes after logging `1`.
* `await b()` receives the unhandled rejected promise from `b()`, throwing an uncaught promise rejection with the value `2`.
