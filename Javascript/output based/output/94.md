### Step-by-Step Breakdown

**Core Rule (`String.prototype.length` & UTF-16 Code Units):**

* In JavaScript, `String.prototype.length` does not count perceived visual characters (grapheme clusters) or full Unicode code points; it returns the number of **UTF-16 code units** in the string.
* Characters in the Basic Multilingual Plane (BMP, code points `U+0000` to `U+FFFF`) require a single 16-bit code unit (`length: 1`).
* Characters outside the BMP (supplementary planes, code points `U+10000` to `U+10FFFF`), such as most emoji, cannot fit into 16 bits. They are represented in UTF-16 using a **surrogate pair** (two 16-bit code units).

---

1. The `'👍'` (thumbs-up) emoji has the Unicode code point **`U+1F44D`**.
2. In UTF-16, `U+1F44D` is encoded as the surrogate pair:

* High surrogate: `\uD83D`
* Low surrogate: `\uDC4D`

1. Since it consists of **2** UTF-16 code units, `'👍'.length` evaluates to **`2`**.
