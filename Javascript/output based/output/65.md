```js
var foo = function bar(){ 
  return 'BFE'; 
};

console.log(foo());
console.log(bar());
```

**Output:**

```javascript
"BFE"
// Uncaught ReferenceError: bar is not defined
```

---

### Step-by-Step Breakdown

**Core Rule (Named Function Expressions — NFE):**

* In a Named Function Expression (`var foo = function bar() { ... }`), the identifier `bar` is **only bound locally inside the function's own scope** (useful for recursion or stack traces).
* The outer/enclosing scope only receives the variable `foo`. The identifier `bar` is **not** defined in the outer scope.

---

1. **`console.log(foo())` $\rightarrow$ `"BFE"**`

* The variable `foo` references the function and is accessible in the outer scope.
* Invoking `foo()` returns `'BFE'`, which logs **`"BFE"`**.

1. **`console.log(bar())` $\rightarrow$ `ReferenceError**`

* JavaScript searches the outer scope for an identifier named `bar`.
* Since `bar` does not exist outside the function's internal body, attempting to access it throws:
**`Uncaught ReferenceError: bar is not defined`**.
