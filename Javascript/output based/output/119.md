```js
function* gen() {
  try {
    yield 1
    yield 2
    return 3
    yield 4
  } finally {
    yield 5
    return 6
    yield 7
  }
}

console.log([...gen()])
```

**Output:**

```javascript
[1, 2, 5]

```

### Step-by-Step Breakdown

**Core Rules (`try...finally` in Generators & Spread Syntax):**

* **`finally` Execution Guarantee:** When a `return` statement is encountered inside a `try` block, execution does not exit immediately; it enters the `finally` block first.
* **`yield` Inside `finally`:** If a `yield` is encountered inside `finally`, the generator pauses and yields that value with `{ done: false }`.
* **Return Overriding:** A `return` inside a `finally` block overrides any previous pending `return` from the `try` block.
* **Spread Operator (`[...]`):** Consumes values from the iterator where `done: false`. The final value associated with `done: true` (from a `return`) is discarded by spread syntax and `for...of` loops.

---

1. **First Iteration (`g.next()`):**

* Enters `try` block and hits `yield 1`.
* Yields `{ value: 1, done: false }` $\rightarrow$ collects **`1`**.

1. **Second Iteration (`g.next()`):**

* Hits `yield 2`.
* Yields `{ value: 2, done: false }` $\rightarrow$ collects **`2`**.

1. **Third Iteration (`g.next()`):**

* Encounters `return 3`. Before completing the return, control transfers to the `finally` block.
* Inside `finally`, it encounters `yield 5`.
* Yields `{ value: 5, done: false }` $\rightarrow$ collects **`5`**.
* *(Note: `yield 4` in the `try` block was skipped due to `return 3`)*.

1. **Fourth Iteration (`g.next()`):**

* Resumes inside `finally` and hits `return 6`.
* This overrides `return 3` and terminates the generator with `{ value: 6, done: true }`.
* Because `done` is `true`, `6` is not included in the resulting array.

Resulting array: **`[1, 2, 5]`**.
