# File 104

```js
class A {
  a = 'a'
}

A.prototype.c = 'c'

class B extends A {
  b = 'b'
}

const a = new A()
const b = new B()

console.log(a.a)
console.log(a.b)
console.log(a.c)
console.log(b.a)
console.log(b.b)
console.log(b.c)
```

undefined
"c"
"a"
"b"

### Step-by-Step Breakdown

**Core Rules (Class Field Inheritance & Prototype Chain):**

1. **Public Class Fields:** Defined on the instance itself during instantiation (as own properties), not on the prototype.
2. **Derived Class Construction (`extends`):** When `new B()` runs, the default constructor implicitly calls `super()`, initializing the inherited instance fields from class `A` (`a.a = 'a'`), followed by its own fields (`b.b = 'b'`).
3. **Prototype Inheritance:** The prototype chain is linked such that:

$$\text{instance } b \rightarrow B\text{.prototype} \rightarrow A\text{.prototype} \rightarrow \text{Object.prototype} \rightarrow \text{null}$$

1. **Inspecting instance `a` (`new A()`):**

* **`a.a` $\rightarrow$ `"a"**` (own property on `a`).
* **`a.b` $\rightarrow$ `undefined**` (property `b` only exists on derived instances of `B`).
* **`a.c` $\rightarrow$ `"c"**` (found on `A.prototype`).

1. **Inspecting instance `b` (`new B()`):**

* **`b.a` $\rightarrow$ `"a"**` (own property initialized via base class `A`'s constructor).
* **`b.b` $\rightarrow$ `"b"**` (own property initialized via class `B`'s constructor).
* **`b.c` $\rightarrow$ `"c"**` (resolved via the prototype chain: $b \rightarrow B\text{.prototype} \rightarrow A\text{.prototype.c}$).
