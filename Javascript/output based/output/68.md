```js
// This is a JavaScript Quiz from BFE.dev

if (function foo(){ console.log('BFE') }) {
  console.log('dev')
}
foo()
```

**Output:**

```javascript
"dev"
// Uncaught ReferenceError: foo is not defined

```

---

### Step-by-Step Breakdown

**Core Rule (Function Declarations vs. Function Expressions):**

* The syntax for an `if` statement is `if ( Expression ) Statement`.
* Because `function foo() { ... }` appears inside the condition parentheses `( ... )`, it is parsed as a **Named Function Expression (NFE)**, not a function declaration.
* In a Named Function Expression, the name `foo` is only bound **inside its own function body**; it is never added or hoisted to the enclosing outer scope.

---

1. **Evaluating the `if` Condition:**

* The function expression evaluates to a function object.
* All objects in JavaScript are **truthy**.
* The condition passes, entering the `if` block and executing `console.log('dev')` $\rightarrow$ logs **`"dev"`**.

1. **Evaluating `foo()`:**

* JavaScript searches the outer scope for an identifier named `foo`.
* Because `foo` was defined only as a local identifier to the function expression inside the `if` condition, it does not exist in the outer scope.
* Invoking `foo()` throws: **`Uncaught ReferenceError: foo is not defined`**.
