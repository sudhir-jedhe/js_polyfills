### Step-by-Step Breakdown

**Core Rules (`Promise.all` & `await` Rejections):**

* **Fail-Fast in `Promise.all`:** `Promise.all` rejects immediately upon the first input promise that rejects, ignoring any subsequent or pending promises, and passes the rejection reason directly.
* **`await` with Rejections:** When `await` is used on a rejected promise inside an `async` function, it unpacks the rejection reason and throws it as an unhandled exception within the function scope.
* An uncaught exception inside an `async` function causes the outer promise returned by that function to reject with the thrown value.
