let a = 1
const b = ++a
const c = a++
console.log(a)
console.log(b)
console.log(c)

**Output:**

```javascript
3
2
2

```

---

### Step-by-Step Breakdown

1. **`let a = 1`**

* Initializes `a` with value `1`.

1. **`const b = ++a` (Prefix Increment)**

* Increments `a` first: `a` becomes `2`.
* Returns the updated value (`2`) and assigns it to `b`.
* Current state: `a = 2`, `b = 2`.

1. **`const c = a++` (Postfix Increment)**

* Evaluates to the current value of `a` (`2`) first and assigns it to `c`.
* Increments `a` afterward: `a` becomes `3`.
* Current state: `a = 3`, `b = 2`, `c = 2`.

1. **Logging:**

* `console.log(a)` $\rightarrow$ logs **`3`**
* `console.log(b)` $\rightarrow$ logs **`2`**
* `console.log(c)` $\rightarrow$ logs **`2`**
