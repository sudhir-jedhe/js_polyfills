```js
const a = {
  dev: 'BFE.dev',
  update: name => {
    this.dev = name
  }
}
a.update('bigfrontend.dev')
console.log(a.dev)
```

**Output:**

```javascript

```

### Step-by-Step Breakdown

**Core Rule (Arrow Functions & Lexical `this`):**

* Arrow functions do not define their own `this` binding. Instead, they retain the `this` value of the enclosing lexical scope at the time they are defined.
* Object literals (`{ ... }`) do **not** create a new execution context or lexical scope for `this`.

---

1. **`update` Definition:**

* Because `update` is an arrow function defined in the outer scope, its `this` is lexically bound to the outer execution context (e.g., `window` in a browser or `module.exports`/`undefined` in Node.js), **not** the object `a`.

1. **`a.update('bigfrontend.dev')` Execution:**

* Calling `update` sets `this.dev = 'bigfrontend.dev'`, mutating property `dev` on the outer lexical `this` (such as `window.dev`).
* The property `a.dev` on object `a` remains untouched.

1. **`console.log(a.dev)`:**

* Reads the unchanged property on `a`.
* Logs **`"BFE.dev"`**.
