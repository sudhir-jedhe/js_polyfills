# File 114

```js
function A() {
  this.dev1 = 'BFE'
  this.dev2 = 'dev'
  return {
    dev1: 'bigfrontend'
  }
}

const a = new A()
console.log(a.dev1)
console.log(a.dev2)

```

**Output:**

```javascript
"bigfrontend"
undefined

```

---

### Step-by-Step Breakdown

**Core Rule (Constructor Return Values with `new`):**

* When a function is called as a constructor using the `new` operator:
* If the constructor explicitly returns a **non-primitive object** (such as `{}`), that returned object completely overrides and replaces the newly constructed `this` instance.
* If the constructor returns a **primitive** (or has no explicit `return`), the `return` statement is ignored and the newly created `this` instance is returned instead.

---

1. **`new A()` Execution:**

* During execution, `this.dev1 = 'BFE'` and `this.dev2 = 'dev'` are set on the newly created instance.
* However, `A` explicitly executes `return { dev1: 'bigfrontend' }`.
* Since the return value is an object, JavaScript discards the original `this` instance and assigns the returned object literal `{ dev1: 'bigfrontend' }` to `a`.

1. **`console.log(a.dev1)`:**

* Reads property `dev1` on the returned object $\rightarrow$ **`"bigfrontend"`**.

1. **`console.log(a.dev2)`:**

* Looks for property `dev2` on the returned object `{ dev1: 'bigfrontend' }`.
* Since `dev2` was only attached to the discarded `this` instance, it does not exist on `a` $\rightarrow$ evaluates to **`undefined`**.
