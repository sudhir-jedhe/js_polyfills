# File 45

```js
// This is a JavaScript Quiz from BFE.dev

var foo = 1;
(function () {
  console.log(foo);
  foo = 2;
  console.log(window.foo);
  console.log(foo);
  var foo = 3;
  console.log(foo);
  console.log(window.foo)
})()
```

**Output:**

```javascript
undefined
1
2
3
1

```

---

### Step-by-Step Breakdown

**Core Hoisting Rule:**

* The declaration `var foo` inside the IIFE is hoisted to the top of the function's local scope and initialized to `undefined`.
* This local binding **shadows** the outer/global `var foo = 1` for all unqualified identifier lookups (`foo`) within the function.

---

1. **`console.log(foo)` $\rightarrow$ `undefined**`

* Reads the hoisted local `var foo` before any assignment has taken place.

1. **`foo = 2`**

* Assigns `2` to the **local** `foo` variable. The global `window.foo` remains untouched.

1. **`console.log(window.foo)` $\rightarrow$ `1**`

* Directly accesses the global property on `window`, which still holds the value `1`.

1. **`console.log(foo)` $\rightarrow$ `2**`

* Reads the local `foo`, which was just updated to `2`.

1. **`var foo = 3; console.log(foo)` $\rightarrow$ `3**`

* Assigns `3` to the local `foo` and logs it.

1. **`console.log(window.foo)` $\rightarrow$ `1**`

* Accesses the global `window.foo`, which was never modified and remains `1`.
