```js
console.log(1)
const promise = new Promise((resolve) => {
  console.log(2)
  resolve()
  console.log(3)
})

console.log(4)

promise.then(() => {
  console.log(5)
}).then(() => {
  console.log(6)
})

console.log(7)

setTimeout(() => {
  console.log(8)
}, 10)

setTimeout(() => {
  console.log(9)
}, 0)

```

**Output:**

```javascript
1
2
3
4
7
5
6
9
8

```

**Step-by-Step Breakdown:**

1. **Synchronous Execution (Call Stack):**

* `console.log(1)` logs **`1`**.
* `new Promise((resolve) => { ... })`: The executor runs **synchronously**:
* `console.log(2)` logs **`2`**.
* `resolve()` resolves the promise (marks it ready, schedules downstream microtasks).
* `console.log(3)` logs **`3`**.

* `console.log(4)` logs **`4`**.
* `promise.then(...)`: The first `.then()` callback (`() => console.log(5)`) is enqueued into the **Microtask Queue**.
* `console.log(7)` logs **`7`**.
* First `setTimeout(..., 10)` is scheduled in the **Macrotask/Timer Queue** (delay: 10ms).
* Second `setTimeout(..., 0)` is scheduled in the **Macrotask/Timer Queue** (delay: 0ms).

1. **Microtask Queue Processing:**

* `() => console.log(5)` runs, logs **`5`**.
* The chained `.then()` callback (`() => console.log(6)`) is now enqueued in the **Microtask Queue** and runs immediately after, logging **`6`**.

1. **Macrotask Queue Processing:**

* `setTimeout` with `0ms` delay fires first, logging **`9`**.
* `setTimeout` with `10ms` delay fires next, logging **`8`**.

**Output:**

```javascript
1
2
3
4
7
5
6
9
8

```

   - Logs: 4

5. console.log(7) runs on the Call Stack:

8. Main script completes. The Call Stack is now empty.
