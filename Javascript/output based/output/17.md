### Step-by-Step Breakdown

**Core Rules of `Array.prototype.reduce(callback, initialValue)`:**

* **Without `initialValue`:**
* The accumulator (`a`) starts as the **first element** (`array[0]`).
* Iteration begins at **index 1**, so `b` starts as `array[1]`.
* If the callback does not explicitly return a value, the accumulator becomes `undefined` for all subsequent iterations.

* **With `initialValue`:**
* The accumulator (`a`) starts as `initialValue`.
* Iteration begins at **index 0**, so `b` starts as `array[0]`.

**Snippet 1: `[1, 2, 3].reduce(...)` (No initial value)**

1. **Iteration 1 (Index 1):**

* `a = 1` (taken from `array[0]`), `b = 2` (from `array[1]`)
* `console.log(a, b)` $\rightarrow$ logs **`1 2`**
* No `return` statement $\rightarrow$ implicitly returns `undefined`.

1. **Iteration 2 (Index 2):**

* `a = undefined` (result of previous step), `b = 3`
* `console.log(a, b)` $\rightarrow$ logs **`undefined 3`**
