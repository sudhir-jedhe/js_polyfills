# File 112

```js
const symbol = Symbol('BFE')

const a = {
  [symbol]: 'BFE',
  BFE: 'BFE'
}

console.log(symbol in a)
console.log('BFE' in a)
console.log(Object.keys(a).length)
```

**Output:**

```javascript
true
true
1

```

---

### Step-by-Step Breakdown

**Core Rules (`in` Operator vs. `Object.keys()` with Symbols):**

* **The `in` Operator:** Checks for the presence of a property on an object (or its prototype chain) and supports both **string** and **symbol** keys.
* **`Object.keys()`:** Returns an array containing only the object's own enumerable **string-keyed** properties, completely ignoring symbol-keyed properties.

---

1. **`symbol in a` $\rightarrow$ `true**`

* The `in` operator finds the symbol property `[symbol]` defined directly on object `a`.

1. **`'BFE' in a` $\rightarrow$ `true**`

* The `in` operator finds the string property `'BFE'` on object `a`.

1. **`Object.keys(a).length` $\rightarrow$ `1**`

* `Object.keys(a)` only collects string keys, returning `['BFE']`.
* The symbol key is ignored, so the returned array has a length of **`1`**.

*(To retrieve symbol keys, you can use `Object.getOwnPropertySymbols(a)` or `Reflect.ownKeys(a)`).*
