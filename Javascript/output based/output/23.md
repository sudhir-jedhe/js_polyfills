```js
(async () => {
  await Promise.all([]).then((value) => {
    console.log(value)
  }, (error) => {
    console.log(error)
  })
  
  await Promise.all([1,2,Promise.resolve(3), Promise.resolve(4)]).then((value) => {
    console.log(value)
  }, (error) => {
    console.log(error)
  })
  
  await Promise.all([1,2,Promise.resolve(3), Promise.reject('error')]).then((value) => {
    console.log(value)
  }, (error) => {
    console.log(error)
  })
})()
           
```

### Step-by-Step Breakdown

1. **`Promise.all([])`:**

* Passing an empty iterable to `Promise.all()` resolves **synchronously** to an empty array `[]`.
* The first `.then()` handler logs: `[]`.

1. **`Promise.all([1, 2, Promise.resolve(3), Promise.resolve(4)])`:**

* Non-promise values (like `1` and `2`) are automatically wrapped via `Promise.resolve()`.
* All promises resolve successfully, keeping the input order.
* The first `.then()` handler logs: `[1, 2, 3, 4]`.

1. **`Promise.all([1, 2, Promise.resolve(3), Promise.reject('error')])`:**

* `Promise.all` follows an **all-or-nothing (fail-fast)** strategy.
* As soon as any promise in the iterable rejects (`Promise.reject('error')`), the returned promise immediately rejects with that reason.
* The rejection handler (the second callback in `.then()`) triggers and logs: `"error"`.
