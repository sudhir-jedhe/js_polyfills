### Step-by-Step Breakdown

**Core Rule:**

* `RegExp.prototype.test(arg)` automatically converts its argument to a string (`ToString(arg)`) before running the regular expression match.
* The regular expression `/^4\d\d$/` matches any 3-character string that begins with `4` followed by exactly two digits (`0-9`).

---

1. **`/^4\d\d$/.test('404')` $\rightarrow$ `true**`

* The argument is already the string `'404'`, which matches the pattern.

1. **`/^4\d\d$/.test(404)` $\rightarrow$ `true**`

* Number `404` is coerced to `'404'`, which matches the pattern.

1. **`/^4\d\d$/.test(['404'])` $\rightarrow$ `true**`

* Single-element array `['404']` is converted via `['404'].toString()` to `'404'`, which matches the pattern.

1. **`/^4\d\d$/.test([404])` $\rightarrow$ `true**`

* Single-element array `[404]` is converted via `[404].toString()` to `'404'`, which matches the pattern.
