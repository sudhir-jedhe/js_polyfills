```js
// This is a JavaScript Quiz from BFE.dev


function a() {
  console.log(1)
  return {
    a: function() {
      console.log(2)
      return a()
    }
  }
}

a().a()
```

**Output:**

```javascript
1
2
1

```

---

### Step-by-Step Breakdown

1. **First call: `a()**`

* The outer function `a()` executes.
* `console.log(1)` logs: **`1`**.
* Returns an object `{ a: function() { ... } }`.

1. **Second call: `.a()` on the returned object**

* Invokes the method `a` on the returned object.
* `console.log(2)` logs: **`2`**.
* Executes `return a()`, which refers to the outer function `a` in scope.

1. **Inner recursion: `a()**`

* The outer function `a()` is called again.
* `console.log(1)` logs: **`1`**.
* Returns a new object (its return value is not chained further).
