```js
const createPromise = () => Promise.resolve(1)

function func1() {
  createPromise().then(console.log)
  console.log(2)
}

async function func2() {
  await createPromise()
  console.log(3)
}

console.log(4)
func1()
func2()
```

**Output:**

```javascript
4
2
1
3

```

### Step-by-Step Breakdown

**Core Rules (Event Loop & Microtask Execution):**

1. **Synchronous code** runs first to completion on the call stack.
2. `.then()` callbacks and resumes from `await` expressions are scheduled as **microtasks**.
3. Microtasks execute in FIFO (First-In, First-Out) order once the synchronous call stack is empty.

---

1. **`console.log(4)`:**

* Synchronously logs **`4`**.

1. **`func1()` execution:**

* `createPromise()` returns a resolved promise with value `1`.
* `.then(console.log)` queues **Microtask 1** (`console.log(1)`).
* `console.log(2)` runs synchronously: logs **`2`**.

1. **`func2()` execution:**

* `await createPromise()` evaluates the already-resolved promise and queues the remainder of `func2` as **Microtask 2** (`console.log(3)`).
* Function yields and returns a pending promise.

1. **Microtask Queue Execution:**

* **Microtask 1** runs: logs **`1`**.
* **Microtask 2** runs: logs **`3`**.
