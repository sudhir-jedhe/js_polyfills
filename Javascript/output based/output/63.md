---

### Step-by-Step Breakdown

**Core Rule (`in` Operator):**

* The `in` operator checks whether a specified property key exists in an object or its prototype chain: `prop in object`.
* If the left-hand operand is not a string or symbol, it is coerced to a property key using `ToPropertyKey()`, which calls `ToString()`.

---

1. **`'foo' in obj` $\rightarrow$ `true**`

* The left operand is already the string `'foo'`.
* `'foo'` exists as an own property on `obj`.

1. **`['foo'] in obj` $\rightarrow$ `true**`

* The left operand is an array `['foo']`.
* Coercing `['foo']` to a property key invokes `['foo'].toString()`, which returns the string `"foo"`.
* The evaluation becomes `"foo" in obj`, which evaluates to **`true`**.
