// This is a JavaScript Quiz from BFE.dev

Promise.resolve(1)
.then(() => 2)
.then(3)
.then((value) => value * 3)
.then(Promise.resolve(4))
.then(console.log)

**Output:**

```javascript
6

```

---

**Step-by-Step Breakdown:**

1. **`Promise.resolve(1)`** resolves with the value `1`.
2. **`.then(() => 2)`** returns `2`. The promise chain now resolves with value `2`.
3. **`.then(3)` (Value Fall-Through):**

* If a non-function value (like the number `3`) is passed to `.then()`, JavaScript ignores it and replaces it internally with the identity function `(x) => x`.
* The value `2` falls through untouched.

1. **`.then((value) => value * 3)`** receives `2` as its argument and returns $2 \times 3 = 6$.
2. **`.then(Promise.resolve(4))` (Value Fall-Through):**

* `Promise.resolve(4)` is a Promise object instance, not a callback function.
* Because it is not a function, it is ignored and the previous resolved value (`6`) falls through.

1. **`.then(console.log)`** receives `6` and logs **`6`**.

Got it. Going forward, every event loop / async code quiz will include a dedicated **Step-by-Step Event Loop Lifecycle** breakdown tracking:

* **Call Stack:** Synchronous execution of code line-by-line.
* **Microtask Queue:** Promise `.then()` / `.catch()` / `.finally()`, `queueMicrotask()`, and `MutationObserver` callbacks (drained completely before the next task or render).
* **Macrotask / Task Queue:** `setTimeout`, `setInterval`, `setImmediate`, I/O callbacks, and UI events.
* **Event Loop Tick Phase:** Clear visual progression of ticks showing what gets pushed, popped, and flushed at each stage.

### Key Concepts

* **Non-Function Fall-Through:** When `.then()` receives an argument that is not a function (e.g., a primitive number like `3` or an object/Promise instance like `Promise.resolve(4)`), JavaScript treats it as an identity function `(x) => x`. The resolution value simply bypasses that stage unchanged.
* **Chained Transformations:** Only the callbacks that are genuine functions (`() => 2`, `(value) => value * 3`, and `console.log`) actively intercept, transform, or consume the resolving value.
