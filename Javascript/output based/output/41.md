### Step-by-Step Breakdown

**Core Rules:**

* **Object Literals do not create a `this` scope:** Properties defined inside an object literal evaluate their expressions in the enclosing lexical execution context (here, the global context).
* **Arrow Functions:** Do not bind their own `this`; they inherit `this` from the enclosing lexical scope where they are defined.
* **Standard Methods:** Bind `this` to the object they are called on (e.g., `obj.method()`).

---

1. **`console.log(obj.b)` $\rightarrow$ `NaN**`

* The expression `this.a + 1` executes during object creation in the global scope.
* In global scope, `this.a` is `undefined`.
* `undefined + 1` evaluates to **`NaN`**.

1. **`console.log(obj.c())` $\rightarrow$ `NaN**`

* `c` is an arrow function defined at the top/global level.
* It captures the global `this`. Calling `obj.c()` evaluates `this.a + 1` as `undefined + 1` $\rightarrow$ **`NaN`**.

1. **`console.log(obj.d())` $\rightarrow$ `2**`

* `d` is a standard method invoked as `obj.d()`.
* `this` binds to `obj`, where `this.a` is `1`.
* `1 + 1` evaluates to **`2`**.

1. **`console.log(obj.e())` $\rightarrow$ `2**`

* `e` is a standard method invoked as `obj.e()`, so inside `e`, `this` points to `obj`.
* The arrow function inside `e` lexically captures `e`'s `this` binding (`obj`).
* Executing the IIFE evaluates `obj.a + 1` $\rightarrow$ `1 + 1` $\rightarrow$ **`2`**.
