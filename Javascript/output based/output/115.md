### Step-by-Step Breakdown

**Core Rules (`parseInt(string, radix)`):**

* **Whitespace & Leading Zeros:** Leading whitespace is ignored. Leading zeros are also ignored (since ECMAScript 5, strings starting with `0` are parsed as decimal `radix = 10`, unless prefixed with `0x`/`0X` for hexadecimal).
* **Character Parsing:** Parsing begins at the first non-whitespace character and proceeds character-by-character until it encounters a character that is invalid for the specified radix (in base 10, valid digits are `0-9`).
* **Scientific Notation:** `parseInt` does **not** support scientific notation (`e` or `E`). When it encounters the letter `'e'`, it stops parsing immediately and returns the integer parsed up to that point. (Unlike `Number()` or `parseFloat()`, which parse exponential notation).

---

1. **`parseInt(' 1')` $\rightarrow$ `1**`

* Trims leading space, parses `'1'` $\rightarrow$ **`1`**.

1. **`parseInt(' 00001')` $\rightarrow$ `1**`

* Trims leading space, ignores leading zeros, parses `'1'` $\rightarrow$ **`1`**.

1. **`parseInt(' 0100')` $\rightarrow$ `100**`

* Trims leading space, parses digits `'1'`, `'0'`, `'0'` as base 10 $\rightarrow$ **`100`**.

1. **`parseInt(' 1e2 ')` $\rightarrow$ `1**`

* Trims leading space, parses digit `'1'`.
* Encounters character `'e'`, which is not a valid base-10 digit, so parsing stops immediately and returns the accumulated value **`1`**.
