### Step-by-Step Breakdown

**Core Rules (`Generator.prototype.return()` & `finally` Blocks):**

* Calling `generator.return()` terminates the generator immediately and transitions its status to completed (`done: true`).
* If the generator is paused inside a `try` block when `return()` is called, JavaScript guarantees execution of the accompanying `finally` block before closing the generator.

---

1. **`const obj = g()`:**

* Creates and initializes the generator instance in a suspended state.

1. **`obj.next()` Execution:**

* Enters the generator function and runs `console.log(1)` $\rightarrow$ logs **`1`**.
* Enters the `try` block and runs `console.log(2)` $\rightarrow$ logs **`2`**.
* Reaches `yield 2` and pauses execution, returning `{ value: 2, done: false }`.

1. **`obj.return()` Execution:**

* Invoked while the generator is paused at `yield 2` inside the `try` block.
* Execution immediately transfers control to the `finally` block, bypassing any remaining code in the `try` block (`console.log(3)` and the error throw are never reached).
* Runs `console.log(4)` inside `finally` $\rightarrow$ logs **`4`**.
* The generator completes its return, closing with `{ value: undefined, done: true }`.
