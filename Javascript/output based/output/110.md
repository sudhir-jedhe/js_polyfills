# File 110

```js
function* genA() {
  yield [1, 2, 3]
}

function* genB() {
  yield* [1, 2, 3]
}

console.log(genA().next().value)
console.log(genB().next().value)

```

**Output:**

```javascript
[1, 2, 3]
1

```

---

### Step-by-Step Breakdown

**Core Rule (`yield` vs. `yield*` Delegation):**

* **`yield expression`:** Pauses the generator and returns the value of the `expression` directly as the `value` property of the result object `{ value, done: false }`.
* **`yield* iterable`:** Delegates iteration to another iterable object (such as an Array, Set, or another Generator), iterating through it and yielding each element one by one on subsequent `.next()` calls.

---

1. **`console.log(genA().next().value)` $\rightarrow$ `[1, 2, 3]**`

* `genA` uses regular `yield [1, 2, 3]`.
* The first `.next()` call yields the entire array instance as a single unit: `{ value: [1, 2, 3], done: false }`.
* Accessing `.value` returns **`[1, 2, 3]`**.

1. **`console.log(genB().next().value)` $\rightarrow$ `1**`

* `genB` uses `yield* [1, 2, 3]`, delegating to the array's iterator.
* The first `.next()` call pulls the first element from the array: `{ value: 1, done: false }`.
* Accessing `.value` returns **`1`**.
