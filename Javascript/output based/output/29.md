# File 29

```js
// This is a JavaScript Quiz from BFE.dev

var a = 1

function func() {
  a = 2
  console.log(a)
  var a
}

func()

console.log(a)

if (!('b' in window)) {
  var b = 1
}

console.log(b)
```

**Output:**

*(Assuming execution in a browser environment)*

```javascript
2
1
undefined

```

---

### Step-by-Step Breakdown

1. **Inside `func()`:**

* Due to variable hoisting, `var a` declared at the bottom of `func` is hoisted to the top of `func`'s local function scope.
* `a = 2` assigns `2` to the **local** `a`, leaving the global `a` completely untouched.
* `console.log(a)` inside `func` logs the local variable: **`2`**.

1. **Global `console.log(a)`:**

* Global `a` was never modified by `func()`, so it remains **`1`**.

1. **`var b` and the `if` check:**

* `var` is function-scoped (or globally scoped), not block-scoped.
* In a browser environment, global `var` declarations are automatically hoisted and attached as properties to the global `window` object (initialized to `undefined`).
* Therefore, before any code runs, `'b' in window` evaluates to `true`.
* The condition `!('b' in window)` evaluates to `!true` $\rightarrow$ `false`, so the block `b = 1` **never runs**.
* `console.log(b)` prints the hoisted, unassigned initial value: **`undefined`**.
