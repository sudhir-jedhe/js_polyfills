
```js
Promise.resolve(1)
.then((val) => {
  console.log(val)
  return val + 1
}).then((val) => {
  console.log(val)
}).then((val) => {
  console.log(val)
  return Promise.resolve(3)
    .then((val) => {
      console.log(val)
    })
}).then((val) => {
  console.log(val)
  return Promise.reject(4)
}).catch((val) => {
  console.log(val)
}).finally((val) => {
  console.log(val)
  return 10
}).then((val) => {
  console.log(val)
})
```

**Output:**

```javascript
1
2
undefined
3
undefined
4
undefined
undefined

```

### Key JavaScript Concepts in This Quiz

* **Default Return Value:** If a `.then()` handler has no explicit `return`, it implicitly returns `undefined`, which becomes the resolved value for the next handler.
* **Returning Promises in `.then()`:** When a `.then()` callback returns a Promise, the outer chain pauses and adopts both the resolution state and value of that returned inner Promise.
* **`.catch()` Recovers the Chain:** A `.catch()` handler intercepts rejections; returning a value (or `undefined`) restores the promise chain back to the **fulfilled** state.
* **`.finally()` Semantics:**
* `.finally()` callbacks receive **no arguments** (evaluates as `undefined`).
* Values returned from `.finally()` are **silently ignored** (unless it returns a rejected promise or throws). The previous resolved value passes right through.
