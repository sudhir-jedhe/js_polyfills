# File 39

```js
// This is a JavaScript Quiz from BFE.dev

function foo() {
  console.log(i)
  for (var i = 0; i < 3; i++) {
    console.log(i)
  }
}

foo()
```

**Output:**

```javascript
undefined
0
1
2

```

---

### Step-by-Step Breakdown

1. **Hoisting of `var i`:**

* `var` is function-scoped, not block-scoped.
* The declaration `var i` inside the `for` loop header is hoisted to the top of `foo()` and automatically initialized to `undefined`.

1. **First `console.log(i)` $\rightarrow$ `undefined**`

* Executes before the `for` loop initialization runs, reading the hoisted `undefined`.

1. **`for` Loop Execution:**

* `i = 0`: logs **`0`**
* `i = 1`: logs **`1`**
* `i = 2`: logs **`2`**
* `i` increments to `3`, failing the condition `i < 3` and terminating the loop.
