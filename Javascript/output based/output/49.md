```js
// This is a JavaScript Quiz from BFE.dev

var bar = 1

function foo() {
  return this.bar++
}

const a = {
  bar: 10,
  foo1: foo,
  foo2: function() {
    return foo()
  },
} 


console.log(a.foo1.call())
console.log(a.foo1())
console.log(a.foo2.call())
console.log(a.foo2())
```

**Output:**

*(Assuming non-strict browser / global scope)*

```javascript
1
10
2
3

```

### Step-by-Step Breakdown

**Initial State:**

* Global/window scope: `window.bar = 1`
* Object `a`: `a.bar = 10`

---

1. **`a.foo1.call()` $\rightarrow$ `1**`

* Calling `.call()` without arguments in non-strict mode sets `this` to the global object (`window`).
* `foo()` executes `return this.bar++` using `window.bar`.
* Postfix increment returns the original value **`1`**, and updates `window.bar` to `2`.

1. **`a.foo1()` $\rightarrow$ `10**`

* Invoked directly as a method on `a`, so `this` points to object `a`.
* `foo()` executes `return this.bar++` using `a.bar`.
* Postfix increment returns the original value **`10`**, and updates `a.bar` to `11`.

1. **`a.foo2.call()` $\rightarrow$ `2**`

* Invokes `foo2()`. Inside `foo2`, `foo()` is invoked as a plain, standalone function call (`return foo()`).
* Standalone function calls default `this` to `window`.
* `this.bar++` evaluates using `window.bar` (currently `2`).
* Returns **`2`**, and updates `window.bar` to `3`.

1. **`a.foo2()` $\rightarrow$ `3**`

* Invokes `foo2()`. Again, inside `foo2`, `foo()` is executed as a standalone invocation, binding `this` to `window`.
* `this.bar++` evaluates using `window.bar` (currently `3`).
* Returns **`3`**, and updates `window.bar` to `4`.
