```js
function F() {
  this.foo = 'bar'
}

const f = new F()
console.log(f.prototype)
```

**Output:**

```javascript
undefined

```

---

### Step-by-Step Breakdown

* **Functions vs. Instances:**
* Only constructor functions (like `F`) have a `.prototype` property (which is used as the blueprint for objects created via `new F()`).
* Instances created by a constructor function (like `f`) do **not** have a `.prototype` property; their internal prototype link is stored in `[[Prototype]]` (accessible via `Object.getPrototypeOf(f)` or `f.__proto__`).

* **Evaluating `f.prototype`:**
* When attempting property lookup `f.prototype`, JavaScript searches for an own or inherited property named `"prototype"` on instance `f`.
* Since no property named `"prototype"` exists on `f` or its prototype chain, it evaluates to **`undefined`**.
