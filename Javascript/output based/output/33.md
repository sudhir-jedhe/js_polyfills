const obj = {

  }

---

### Step-by-Step Breakdown

**Core Rule (Reference Type & `this`):**

* When accessing a method via standard property access (`obj.b()` or `obj['b']()`), JavaScript evaluates the expression to an internal **Reference Record** (containing `base: obj`, `referencedName: 'b'`). Calling it immediately preserves `this = base (obj)`.
* Grouping parentheses `(obj.b)` do not evaluate or discard the Reference Record, so `(obj.b)()` retains `this = obj`.
* Any **operator evaluation** (ternary `? :`, comma operator `,`, assignment `=`) calls `GetValue()` on the Reference Record, stripping away the `base` object and returning only the standalone function object. When called, `this` defaults to `undefined` (or `window`/`global` in non-strict mode, where `window.a` is `undefined`).

---

1. **`obj.b()` $\rightarrow$ `1**`

* Standard method invocation with `this` bound to `obj`.

1. **`(true ? obj.b : a)()` $\rightarrow$ `undefined**`

* The conditional (ternary) operator evaluates the operand and returns the raw function value, losing the `obj` base reference. `this` becomes global/`undefined`.

1. **`(true, obj.b)()` $\rightarrow$ `undefined**`

* The comma operator evaluates both operands and returns the raw value of the last operand, discarding the reference record. `this` becomes global/`undefined`.

1. **`(3, obj['b'])()` $\rightarrow$ `undefined**`

* Same as above: the comma operator returns the raw function value, losing the `this` binding to `obj`.

1. **`(obj.b)()` $\rightarrow$ `1**`

* Grouping parentheses `(...)` do not perform operations on the Reference Record; the reference to `obj` is preserved, so `this` is `obj`.

1. **`(obj.c = obj.b)()` $\rightarrow$ `undefined**`

* The assignment expression returns the resulting value of the assignment (the raw function), stripping the Reference Record before invocation.
