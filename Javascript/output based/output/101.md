# File 101

```js
console.log([0] == '')
console.log([0] == 0)
```

**Output:**

```javascript
false
true

```

---

### Step-by-Step Breakdown

**Core Rules (Abstract Equality `==` & `ToPrimitive`):**

* When an Object is compared to a Primitive (String or Number), JavaScript calls `ToPrimitive(array, hint: "default")`, which calls `[0].toString()`.
* For an array, `[0].toString()` joins its elements with commas, evaluating to the string **`"0"`**.
* If a String is compared to a Number (`"0" == 0`), the string is converted to a number via `ToNumber("0")` $\rightarrow 0$.
* If both operands are Strings, standard string comparison is used without numeric coercion.

---

1. **`[0] == ''` $\rightarrow$ `false**`

* Coerce array to primitive: `[0].toString()` $\rightarrow `"0"`.
* The comparison becomes `'0' == ''`.
* Both operands are now strings, so JavaScript checks character equality: `'0'` does not equal `''`.
* Evaluates to **`false`**.

1. **`[0] == 0` $\rightarrow$ `true**`

* Coerce array to primitive: `[0].toString()` $\rightarrow `"0"`.
* The comparison becomes `'0' == 0`.
* String vs. Number triggers `ToNumber('0')` $\rightarrow 0$.
* $0 == 0$ evaluates to **`true`**.
