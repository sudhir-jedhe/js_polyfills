# File 70

```js
// This is a JavaScript Quiz from BFE.dev

function foo(){ console.log(1) }
var foo = 2
function foo(){ console.log(3) }
foo()
```

**Output:**

```javascript
// Uncaught TypeError: foo is not a function

```

---

### Step-by-Step Breakdown

**1. Hoisting Phase:**

* Function declarations hoist along with their function definitions.
* First, `foo` is initialized to the function logging `1`.
* Then, the second function declaration `function foo() { console.log(3) }` overwrites `foo` with the function logging `3`.

* Variable declarations (`var foo`) are hoisted next, but because `foo` already exists as an identifier in the scope, the declaration is ignored.

**2. Execution Phase:**

* Function declarations are skipped during runtime execution.
* The assignment `foo = 2` executes, overwriting `foo` with the number `2`.
* `foo()` is called $\rightarrow$ since `foo` is now `2` (a primitive number, not a callable function), JavaScript throws:
**`Uncaught TypeError: foo is not a function`**.
