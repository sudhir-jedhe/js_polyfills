### Step-by-Step Breakdown

**Core Rules (Loose Equality `==` & Left-Associativity):**

* The loose equality operator (`==`) is **left-associative**, meaning expressions evaluate from left to right:
`(((2.0 == "2") == new Boolean(true)) == "1")`
* If operands have different types:
* **Boolean:** Converts to a Number (`true` $\rightarrow 1$, `false` $\rightarrow 0$).
* **String vs. Number:** The String converts to a Number via `ToNumber()`.
* **Primitive vs. Object:** The Object converts to a primitive via `ToPrimitive()`.
