```js
function block(duration = 1000) {
  const start = Date.now()
  while (Date.now() - start < duration) {
    window.timestamp = Date.now()
  }
}

function a() {
   console.log(1)
   block()
   setTimeout(() => console.log(2), 0)
   setTimeout(() => console.log(3), 1)

}

function b() {
  console.log(4)
}

console.log(5)
setTimeout(a, 0)
setTimeout(b, 500)
```

### Step-by-Step Breakdown

**Core Rules (Timers & Event Loop Macrotask Queue):**

* Timers scheduled via `setTimeout` are placed on the host environment's timer list with an expiration target: $T_{\text{target}} = T_{\text{current}} + \text{delay}$.
* When the synchronous thread / call stack is busy or blocked, background time still advances.
* Once the call stack clears, expired timer callbacks in the macrotask queue run in order of their scheduled expiration times.

---

### Execution Timeline (relative to start $T = 0\text{ ms}$)

1. **Synchronous script execution ($T = 0\text{ ms}$):**

* `console.log(5)` runs $\rightarrow$ logs **`5`**.
* `setTimeout(a, 0)` is scheduled $\rightarrow$ Target: $\approx 0\text{ ms}$.
* `setTimeout(b, 500)` is scheduled $\rightarrow$ Target: $\approx 500\text{ ms}$.
* Call stack clears.

1. **First timer `a` executes ($T \approx 0\text{ ms}$):**

* `console.log(1)` runs $\rightarrow$ logs **`1`**.
* `block()` runs a synchronous `while` loop that blocks the thread for **$1000\text{ ms}$**.
* The call stack is occupied until $T \approx 1000\text{ ms}$.
* *(Note: While blocked, at $T \approx 500\text{ ms}$, timer `b` expired in the background and was queued in the timer ready queue).*
* `setTimeout(() => console.log(2), 0)` is scheduled $\rightarrow$ Target: $1000\text{ ms} + 0\text{ ms} = 1000\text{ ms}$.
* `setTimeout(() => console.log(3), 1)` is scheduled $\rightarrow$ Target: $1000\text{ ms} + 1\text{ ms} = 1001\text{ ms}$.
* Function `a` finishes; call stack clears at $T \approx 1000\text{ ms}$.

1. **Processing remaining timers:**

* **`b`** (scheduled for $500\text{ ms}$) is already long overdue $\rightarrow$ runs first and logs **`4`**.
* **`() => console.log(2)`** (scheduled for $1000\text{ ms}$) is next $\rightarrow$ runs and logs **`2`**.
* **`() => console.log(3)`** (scheduled for $1001\text{ ms}$) runs next $\rightarrow$ logs **`3`**.
