```js
// This is a JavaScript Quiz from BFE.dev Arrow Function

const obj = {
  dev: 'bfe',
  a: function() {
    return this.dev
  },
  b() {
    return this.dev
  },
  c: () => {
    return this.dev
  },
  d: function() {
    return (() => {
      return this.dev
    })()
  },
  e: function() {
    return this.b()
  },
  f: function() {
    return this.b
  },
  g: function() {
    return this.c()
  },
  h: function() {
    return this.c
  },
  i: function() {
    return () => {
      return this.dev
    }
  }
}

console.log(obj.a())
console.log(obj.b())
console.log(obj.c())
console.log(obj.d())
console.log(obj.e())
console.log(obj.f()())
console.log(obj.g())
console.log(obj.h()())
console.log(obj.i()())
```

```javascript
bfe

bfe

```

---

### Step-by-Step Breakdown

1. **`obj.a()` $\rightarrow$ `'bfe'**`

* Standard function invoked as a method of `obj`. `this` points to `obj`.

1. **`obj.b()` $\rightarrow$ `'bfe'**`

* ES6 method shorthand behaves like a standard function. Invoked via `obj`, so `this` points to `obj`.

1. **`obj.c()` $\rightarrow$ `undefined**`

* Arrow functions do not bind their own `this`; they inherit `this` from their enclosing lexical scope (the global/module scope where `obj` was declared, not `obj` itself). In global scope, `this.dev` is `undefined`.

1. **`obj.d()` $\rightarrow$ `'bfe'**`

* `d` is called as a method of `obj`, so `d`'s `this` is `obj`.
* Inside `d`, an immediately invoked arrow function inherits `this` from `d`'s scope (`obj`).

1. **`obj.e()` $\rightarrow$ `'bfe'**`

* `e` calls `this.b()`. Since `e` was invoked on `obj`, `this` is `obj`, which directly calls `obj.b()`.

1. **`obj.f()()` $\rightarrow$ `undefined**` *(or `TypeError` in strict mode)*

* `obj.f()` returns the function reference `b`.
* It is immediately called standalone as a function (`()()`).
* Standalone function invocations lose their object binding; `this` defaults to `window`/`global` (or `undefined` in strict mode).

1. **`obj.g()` $\rightarrow$ `undefined**`

* `g` calls `this.c()`, which runs `c` (the arrow function whose lexical `this` is global), returning `undefined`.

1. **`obj.h()()` $\rightarrow$ `undefined**`

* `obj.h()` returns the reference to arrow function `c`.
* Invoking `c()` still retains its lexically bound outer `this` (global scope), returning `undefined`.

1. **`obj.i()()` $\rightarrow$ `'bfe'**`

* `obj.i()` is invoked with `this` bound to `obj`.
* It returns an arrow function which captures that active `this` (`obj`).
* Invoking the returned arrow function retains the captured `obj` reference, returning `'bfe'`.
