```js
// This is a JavaScript Quiz from BFE.dev

let foo = 10
function func1() {
    console.log(foo)
    var foo = 1
}
func1 ()


function func2() {
    console.log(foo)
    let foo = 1
}
func2 ()


```

**Output:**

```javascript
undefined
// Uncaught ReferenceError: Cannot access 'foo' before initialization

```

---

### Step-by-Step Breakdown

1. **Execution of `func1()` $\rightarrow$ `undefined**`

* Inside `func1`, the declaration `var foo` is hoisted to the top of the function scope and initialized to `undefined`.
* This local `foo` shadows the outer `let foo = 10`.
* When `console.log(foo)` runs, it reads the local `foo` before the assignment `foo = 1` takes place, logging **`undefined`**.

1. **Execution of `func2()` $\rightarrow$ `ReferenceError**`

* Inside `func2`, `let foo = 1` creates a local block-scoped binding.
* `let` and `const` declarations are hoisted to the top of their scope but remain **uninitialized** in the **Temporal Dead Zone (TDZ)** until the interpreter reaches the actual declaration line.
* Because the local `foo` shadows the outer `foo = 10`, attempting to read `foo` inside the TDZ throws a **`ReferenceError: Cannot access 'foo' before initialization`**.
