### Step-by-Step Breakdown

**Core Rule (Array Index Limits & `Array.prototype.at()`):**

* In ECMAScript, an **array index** is an integer index $i$ in the range $0 \le i < 2^{32} - 1$ (maximum index is $4{,}294{,}967{,}294$).
* When setting an index within this range, the array's `length` automatically updates to $\text{index} + 1$. The maximum possible array `length` is $2^{32} - 1 = 4{,}294{,}967{,}295$.
* Any property key outside this range (like $2^{32} - 1 = 4{,}294{,}967{,}295$) is **not** treated as an array index—it is treated as a standard non-index string property on the object and does **not** affect `length`.
* `arr.at(-1)` calculates the relative index as `length + (-1) = length - 1`, and accesses `arr[length - 1]`.

---

1. **`arr[(2 ** 32) - 2] = 1`:**

* $(2^{32} - 2) = 4{,}294{,}967{,}294$, which is the maximum valid array index.
* `arr.length` becomes $(2^{32} - 2) + 1 = 2^{32} - 1 = 4{,}294{,}967{,}295$.

1. **`arr[(2 ** 32) - 1] = 2`:**

* $(2^{32} - 1) = 4{,}294{,}967{,}295$, which exceeds the valid index range.
* It is treated as an ordinary object property `"4294967295": 2` and has no effect on `arr.length`.
* `arr.length` remains $4{,}294{,}967{,}295$.

1. **`arr.at(-1)`:**

* Evaluates to `arr[arr.length - 1]`.
* `arr[4294967295 - 1] = arr[4294967294] = arr[(2 ** 32) - 2]`.
* Value at this index is **`1`**.
