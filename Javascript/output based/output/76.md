```js
// This is a JavaScript Quiz from BFE.dev 

function func() {
  const a = b = c = 1
}
func()
console.log(typeof a, typeof b, typeof c)
```

**Output:**

*(In non-strict mode)*

```javascript
"undefined" "number" "number"

```

*(In strict mode `'use strict'`, `b = c = 1` throws `ReferenceError: c is not defined`)*

---

### Step-by-Step Breakdown

**Core Rule (Chained Assignment and Scope):**

* Chained assignment evaluates from right to left: `const a = (b = (c = 1))`.
* Only the first variable `a` is declared with `const`.
* `b` and `c` are undeclared assignments. In non-strict mode, assigning to undeclared variables creates properties on the **global object** (`window.b = 1`, `window.c = 1`).

---

1. **Inside `func()`:**

* `c = 1`: Creates global variable `c`.
* `b = 1`: Creates global variable `b`.
* `const a = 1`: Scoped strictly within `func()`.

1. **Outside `func()`:**

* `typeof a`: `a` is block-scoped to `func()` and does not exist in the outer scope. Using `typeof` on an undeclared identifier safely returns **`"undefined"`**.
* `typeof b`: `b` was created as a global variable with value `1` $\rightarrow$ returns **`"number"`**.
* `typeof c`: `c` was created as a global variable with value `1` $\rightarrow$ returns **`"number"`**.
