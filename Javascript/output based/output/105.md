# File 105

```js
const a = 'BFE.dev'
if (!typeof a === 'string') {
  console.log('string')
} else {
  console.log('not a string')
}
```

**Output:**

```javascript
"not a string"

```

---

### Step-by-Step Breakdown

**Core Rules (Operator Precedence & Associativity):**

* Both the logical NOT operator (`!`) and `typeof` are prefix unary operators.
* Unary operators share the same precedence level (precedence 14) and are evaluated with **right-to-left associativity**.
* Therefore, `!typeof a === 'string'` is evaluated as `(!typeof a) === 'string'`.

---

1. **`typeof a` evaluates first:**

* `typeof 'BFE.dev'` produces the primitive string `"string"`.

1. **`! (Logical NOT)` applies next:**

* `!"string"` coerces the non-empty string `"string"` (truthy) to a boolean $\rightarrow$ **`false`**.

1. **Equality comparison (`===`):**

* The condition becomes `false === 'string'`.
* Since a boolean does not equal a string, this evaluates to **`false`**.

1. **Branch Execution:**

* The `if` branch is skipped and the `else` branch executes.
* Logs **`"not a string"`**.

*(To write this correctly, parentheses are needed: `typeof a !== 'string'` or `!(typeof a === 'string')`)*
