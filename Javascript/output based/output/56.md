### Step-by-Step Breakdown

**Core Rules for Type Coercion:**

* **`Symbol.toPrimitive(hint)`:** Takes highest precedence if defined. Hints are `"number"`, `"string"`, or `"default"`.
* **Binary `+` operator:** Triggers `ToPrimitive(hint: "default")`.
* If `Symbol.toPrimitive` is present, it is invoked with hint `"default"`.
* Otherwise, standard default coercion calls `valueOf()` first, falling back to `toString()`.

* **Unary `+` operator:** Triggers `ToPrimitive(hint: "number")` $\rightarrow$ calls `Symbol.toPrimitive("number")`, or `valueOf()` then `toString()`.
* **`parseInt(string, radix)`:** First performs `ToString()` on its argument:
* Triggers `ToPrimitive(hint: "string")`.
* If `Symbol.toPrimitive` exists, it calls `[Symbol.toPrimitive]('string')`.
* Otherwise, string coercion prioritizes `toString()` first, falling back to `valueOf()`. If `toString()` is not defined, `Object.prototype.toString` returns `"[object Object]"` (which parses as `NaN`).
