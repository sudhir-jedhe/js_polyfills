### Step-by-Step Breakdown

Both equality (`==`) and relational (`<`, `>`) operators have **left-to-right associativity**. Chained comparisons evaluate the first pair into a boolean, which is then coerced into a number (`false` $\rightarrow$ `0`, `true` $\rightarrow$ `1`) when evaluated against the remaining number.

1. **`0 == 1 == 2` $\rightarrow$ `false**`

* `(0 == 1) == 2`
* `false == 2` $\rightarrow$ `0 == 2` $\rightarrow$ **`false`**

1. **`2 == 1 == 0` $\rightarrow$ `true**`

* `(2 == 1) == 0`
* `false == 0` $\rightarrow$ `0 == 0` $\rightarrow$ **`true`**

1. **`0 < 1 < 2` $\rightarrow$ `true**`

* `(0 < 1) < 2`
* `true < 2` $\rightarrow$ `1 < 2` $\rightarrow$ **`true`**

1. **`1 < 2 < 3` $\rightarrow$ `true**`

* `(1 < 2) < 3`
* `true < 3` $\rightarrow$ `1 < 3` $\rightarrow$ **`true`**

1. **`2 > 1 > 0` $\rightarrow$ `true**`

* `(2 > 1) > 0`
* `true > 0` $\rightarrow$ `1 > 0` $\rightarrow$ **`true`**

1. **`3 > 2 > 1` $\rightarrow$ `false**`

* `(3 > 2) > 1`
* `true > 1` $\rightarrow$ `1 > 1` $\rightarrow$ **`false`**
