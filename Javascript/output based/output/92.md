### Step-by-Step Breakdown

**Core Rules (`NaN` Behavior & Comparisons):**

* **IEEE 754 & Equality (`==`, `===`):** `NaN` is not equal to anything, including itself. Both `NaN == NaN` and `NaN === NaN` evaluate to `false`.
* **`Object.is()` (SameValue Algorithm):** Treats `NaN` as equal to `NaN` (`SameValue(NaN, NaN)` is `true`).
* **`Array.prototype.indexOf()` (Strict Equality Comparison):** Uses the `===` algorithm internally. Since `NaN === NaN` is `false`, it fails to find `NaN` and returns `-1`.
* **`Array.prototype.includes()` (SameValueZero Algorithm):** Uses `SameValueZero`, which considers `NaN` equal to `NaN`. Thus, it successfully finds `NaN` and returns `true`.
* **`Math.max()` / `Math.min()`:** If any argument passed to `Math.max` or `Math.min` is `NaN` (or coerces to `NaN`), the result is always `NaN`, regardless of other values like numbers or `Infinity`.
