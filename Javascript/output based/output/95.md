### Step-by-Step Breakdown

**Core Rule (Legacy Octal Literals in Non-Strict Mode):**

* A number literal starting with a leading `0` is interpreted as an **octal (base-8)** number if all of its digits are between `0` and `7`.
* If a number starting with `0` contains the digits `8` or `9` (which are invalid in octal), JavaScript falls back to parsing it as a standard **decimal (base-10)** number.

---

1. **`017 - 011` $\rightarrow$ `6**`

* `017` contains only valid octal digits: $1 \times 8^1 + 7 \times 8^0 = 15$ (decimal).
* `011` contains only valid octal digits: $1 \times 8^1 + 1 \times 8^0 = 9$ (decimal).
* $15 - 9 =$ **`6`**.

1. **`018 - 011` $\rightarrow$ `9**`

* `018` contains the digit `8`, making it invalid octal; it falls back to decimal **`18`**.
* `011` is octal **`9`**.
* $18 - 9 =$ **`9`**.

1. **`019 - 011` $\rightarrow$ `10**`

* `019` contains the digit `9`, making it invalid octal; it falls back to decimal **`19`**.
* `011` is octal **`9`**.
* $19 - 9 =$ **`10`**.
