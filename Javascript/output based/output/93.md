### Step-by-Step Breakdown

**Core Rule (String Immutability):**

* In JavaScript, strings are **primitive** values and are completely **immutable**.
* While bracket notation (`a[0]`) allows read-only access to individual characters, indexed property assignment on primitive strings is not allowed:
* In **non-strict mode**, the assignment `a[0] = 'c'` fails silently with no effect.
* In **strict mode** (`'use strict'`), attempting to mutate a character property on a string throws a `TypeError: Cannot assign to read only property '0' of string`.

2. `a[0] = 'c'` attempts to mutate the first character, but primitives cannot be mutated, so the assignment is ignored.
