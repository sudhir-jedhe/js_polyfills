# File 108

```js
const obj = {}
const a = { name: 'a'}
const b = { name: 'b'}
obj[a] = {...a}
obj[b] = {...b}

console.log(obj[a].name)
console.log(obj[b].name)
```

**Output:**

```javascript
"b"
"b"

```

---

### Step-by-Step Breakdown

**Core Rule (Object Keys String Coercion):**

* Standard JavaScript object keys are always strings or symbols.
* When an object is passed as a key via bracket notation (`obj[key]`), it is coerced to a string by calling `String(key)` / `key.toString()`.
* For a plain object without a custom `toString()` implementation, `({}).toString()` returns the string `"[object Object]"`.

---

1. **`obj[a] = {...a}`:**

* `a` is coerced to the string key `"[object Object]"`.
* `obj["[object Object]"]` is set to `{ name: 'a' }`.

1. **`obj[b] = {...b}`:**

* `b` is also coerced to the string key `"[object Object]"`.
* This overwrites the existing value at `obj["[object Object]"]` with `{ name: 'b' }`.

1. **`console.log(obj[a].name)` & `console.log(obj[b].name)`:**

* Both `obj[a]` and `obj[b]` access `obj["[object Object]"]`.
* Since the property was overwritten by the assignment for `b`, both lookups return `{ name: 'b' }`.
* Logs **`"b"`** twice.
