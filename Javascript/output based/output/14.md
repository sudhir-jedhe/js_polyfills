### Step-by-Step Breakdown

**Core Rules:**

* **Unary Plus (`+x`):** Converts operand `x` to a number first (`+true` $\rightarrow$ `1`, `+null` $\rightarrow$ `0`, `+undefined` $\rightarrow$ `NaN`, `+'2'` $\rightarrow$ `2`).
* **Binary Plus (`a + b`):** If either operand is a string, string concatenation occurs; otherwise, numeric addition is performed.

---

1. **`1 + 2` $\rightarrow$ `3**`

* Numeric addition: $1 + 2 = 3$.

1. **`1 + + 2` $\rightarrow$ `3**`

* `1 + (+2)` $\rightarrow$ `1 + 2` $\rightarrow$ `3`.

1. **`1 + + + 2` $\rightarrow$ `3**`

* `1 + (+ (+2))` $\rightarrow$ `1 + 2` $\rightarrow$ `3`.

1. **`1 + '2'` $\rightarrow$ `"12"**`

* Binary `+` with string $\rightarrow$ String concatenation: `"12"`.

1. **`1 + + '2'` $\rightarrow$ `3**`

* `1 + (+'2')` $\rightarrow$ `+'2'` coerces to number `2` $\rightarrow$ `1 + 2` $\rightarrow$ `3`.

1. **`'1' + 2` $\rightarrow$ `"12"**`

* Binary `+` with string $\rightarrow$ String concatenation: `"12"`.

1. **`'1' + + 2` $\rightarrow$ `"12"**`

* `'1' + (+2)` $\rightarrow$ `'1' + 2` $\rightarrow$ String concatenation: `"12"`.

1. **`1 + true` $\rightarrow$ `2**`

* `Number(true)` is `1` $\rightarrow$ `1 + 1` $\rightarrow$ `2`.

1. **`1 + + true` $\rightarrow$ `2**`

* `1 + (+true)` $\rightarrow$ `1 + 1` $\rightarrow$ `2`.

 1. **`'1' + true` $\rightarrow$ `"1true"**`

* Binary `+` with string $\rightarrow$ String concatenation: `"1true"`.

 1. **`'1' + + true` $\rightarrow$ `"11"**`

* `'1' + (+true)` $\rightarrow$ `'1' + 1` $\rightarrow$ String concatenation: `"11"`.

 1. **`1 + null` $\rightarrow$ `1**`

* `Number(null)` is `0` $\rightarrow$ `1 + 0` $\rightarrow$ `1`.

 1. **`1 + + null` $\rightarrow$ `1**`

* `1 + (+null)` $\rightarrow$ `1 + 0` $\rightarrow$ `1`.

 1. **`'1' + null` $\rightarrow$ `"1null"**`

* Binary `+` with string $\rightarrow$ String concatenation: `"1null"`.

 1. **`'1' + + null` $\rightarrow$ `"10"**`
