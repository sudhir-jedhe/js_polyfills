### Step-by-Step Breakdown

**Core Rules of Loose Equality (`==`):**

* **Object vs Object:** JavaScript compares **memory references**, skipping type coercion entirely.
* **Object vs Primitive (Number/String/Boolean):** JavaScript converts the object to a primitive via `ToPrimitive()` (`valueOf()` / `toString()`).
* **Boolean vs Other Types:** The boolean operand is converted to a number (`true` $\rightarrow$ `1`, `false` $\rightarrow$ `0`).

---

1. **`[1] == 1` $\rightarrow$ `true**`

* `[1]` converts to primitive string `[1].toString()` $\rightarrow$ `"1"`.
* `"1" == 1` coerces `"1"` to number `1` $\rightarrow$ `1 == 1` $\rightarrow$ **`true`**.

1. **`[1] == '1'` $\rightarrow$ `true**`

* `[1].toString()` is `"1"` $\rightarrow$ `"1" == "1"` $\rightarrow$ **`true`**.

1. **`['1'] == '1'` $\rightarrow$ `true**`

* `['1'].toString()` is `"1"` $\rightarrow$ `"1" == "1"` $\rightarrow$ **`true`**.

1. **`['1'] == 1` $\rightarrow$ `true**`

* `['1'].toString()` is `"1"`, then `"1" == 1` $\rightarrow$ `1 == 1` $\rightarrow$ **`true`**.

1. **`[1] == ['1']` $\rightarrow$ `false**`

* Both operands are **objects** (arrays). Comparing two distinct object references in memory evaluates to **`false`**.

1. **`new Boolean(true) == 1` $\rightarrow$ `true**`

* `new Boolean(true)` is an object wrapper. Coercing it to primitive via `.valueOf()` yields `true`.
* `true == 1` coerces to `1 == 1` $\rightarrow$ **`true`**.

1. **`new Boolean(true) == new Boolean(true)` $\rightarrow$ `false**`

* Both sides are distinct **object instances**, so reference equality fails $\rightarrow$ **`false`**.

1. **`Boolean(true) == '1'` $\rightarrow$ `true**`

* `Boolean(true)` returns a primitive `true`.
* `true == '1'` coerces both to numbers: `1 == 1` $\rightarrow$ **`true`**.

1. **`Boolean(false) == [0]` $\rightarrow$ `true**`

* `Boolean(false)` returns primitive `false`.
* `[0]` converts to primitive string `"0"`.
* `false == "0"` coerces both to numbers: `0 == 0` $\rightarrow$ **`true`**.

 1. **`new Boolean(true) == '1'` $\rightarrow$ `true**`

* `new Boolean(true)` is an object, converting to primitive `true`.
* `true == '1'` coerces to `1 == 1` $\rightarrow$ **`true`**.

 1. **`new Boolean(false) == [0]` $\rightarrow$ `false**`

* Both `new Boolean(false)` (wrapper instance) and `[0]` (array instance) are of type **`"object"`**.
* Because both operands are objects, JavaScript performs a **reference equality check** without coercing either value to a primitive $\rightarrow$ **`false`**.

 1. **`null == undefined` $\rightarrow$ `true**`

* By specification, loose equality explicitly defines `null == undefined` as **`true`**.
