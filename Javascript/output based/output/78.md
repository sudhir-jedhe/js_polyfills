# Initial: lastIndex = 0

### Step-by-Step Breakdown

**Core Rule (`RegExp.prototype.test()` with the Global `g` Flag):**

* When a regular expression has the global (`g`) or sticky (`y`) flag, it becomes **stateful**.
* It maintains an internal pointer named **`lastIndex`** that indicates the index at which to start the next match:
* If a match is found, `lastIndex` is updated to the end index of the match.
* If no match is found, `lastIndex` automatically resets back to `0`.

---

1. **Initial State:**

* `regExp.lastIndex = 0`

1. **Iteration 1 (`elem = 'a'`):**

* Starts search at `lastIndex = 0`.
* `'a'` matches `/^[a-z]$/i`.
* Returns **`true`** $\rightarrow$ `'a'` is kept.
* `lastIndex` is set to **`1`**.

1. **Iteration 2 (`elem = 'b'`):**

* Starts search at `lastIndex = 1`.
* Since `'b'` has a length of 1, searching from index 1 starts at the end of the string, so no match is found.
* Returns **`false`** $\rightarrow$ `'b'` is skipped.
* `lastIndex` resets to **`0`**.

1. **Iteration 3 (`elem = 'c'`):**

* Starts search at `lastIndex = 0`.
* `'c'` matches `/^[a-z]$/i`.
* Returns **`true`** $\rightarrow$ `'c'` is kept.
* `lastIndex` is set to **`1`**.

1. **Iteration 4 (`elem = '1'`):**

* Starts search at `lastIndex = 1`.
* No match is found.
* Returns **`false`** $\rightarrow$ `'1'` is skipped.
* `lastIndex` resets to **`0`**.

**Resulting Array:** `["a", "c"]`
