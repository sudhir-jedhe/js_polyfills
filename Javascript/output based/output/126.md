# File 126

```js
console.log([
  ...Object.keys({a: 1, b: 2}),
  ...Object.keys({b: 2, a: 1})
])
```

**Output:**

```javascript
[ 'a', 'b', 'b', 'a' ]

```

---

### Step-by-Step Breakdown

**Core Rule (Property Iteration Order / `OrdinaryOwnPropertyKeys`):**
According to the ECMAScript specification, `Object.keys()` returns property keys in the following deterministic order:

1. **Integer indices** in ascending numeric order (e.g., `'0'`, `'1'`, `'2'`).
2. **String keys** in **chronological insertion order**.
3. **Symbol keys** (which `Object.keys` omits entirely).

---

1. **`Object.keys({a: 1, b: 2})`:**

* Both keys are non-integer strings.
* Preserves insertion order: `['a', 'b']`.

1. **`Object.keys({b: 2, a: 1})`:**

* Both keys are non-integer strings.
* Preserves insertion order: `['b', 'a']`.

1. **Spread syntax `[...]`:**

* Spreads both arrays into a single array literal: `[ 'a', 'b', 'b', 'a' ]`.
