2. **String Concatenation:**

* `'b' + 'a'` $\rightarrow$ `'ba'`
* `'ba' + NaN` $\rightarrow$ `'baNaN'`
* `'baNaN' + 'a'` $\rightarrow$ `'baNaNa'`
