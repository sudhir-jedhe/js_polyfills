```js
// This is a JavaScript Quiz from BFE.dev 



let func = () => {
  console.log(1)
}
setTimeout(() => {
  func = () => {
    console.log(2)
  }
}, 0)

setTimeout(func, 100)
```

**Output:**

```javascript
1

```

---

### Step-by-Step Breakdown

**Core Rule (Pass-by-Value for Arguments):**

* Function arguments in JavaScript are evaluated and passed by value (where object/function references are copied by value).
* Passing `func` to `setTimeout(func, 100)` immediately passes the reference to the **original function object** (`() => console.log(1)`), not a dynamic reference to the variable `func`.

---

1. **Synchronous Execution:**

* `func` is defined with the original function reference ($F_1$).
* First `setTimeout(..., 0)` registers a callback that will reassign the variable `func`.
* Second `setTimeout(func, 100)` evaluates `func` immediately $\rightarrow$ passes reference $F_1$ to the browser's timer API.

1. **0ms Timer Fires:**

* The callback executes and reassigns the variable `func` to a new function ($F_2$).
* However, the 100ms timer was already registered with the original reference $F_1$.

1. **100ms Timer Fires:**

* Executes the registered function $F_1$.
* Logs **`1`**.
