```js
// This is a JavaScript Quiz from BFE.dev

function* gen() {
  yield 2 * (yield 100)
}

const generator = gen()
console.log(generator.next().value)
console.log(generator.next(1).value)
console.log(generator.next(1).value)
```

**Output:**

```javascript
100
2
undefined

```

---

### Step-by-Step Breakdown

**Core Rule (Generator `yield` and `next(value)`):**

* A `yield` expression pauses generator execution and returns the yielded value to the caller (`{ value: ..., done: false }`).
* Passing an argument to `.next(arg)` resumes execution and **replaces the paused `yield` expression** with that argument (`arg`).

---

1. **`console.log(generator.next().value)` $\rightarrow$ `100**`

* Generator execution starts and begins evaluating `yield 2 * (yield 100)`.
* The inner expression `yield 100` is evaluated first.
* Execution pauses and yields `100` with `{ value: 100, done: false }`.
* Logs **`100`**.

1. **`console.log(generator.next(1).value)` $\rightarrow$ `2**`

* Resumes the generator at the inner `yield` and replaces `(yield 100)` with `1`.
* Evaluates `2 * 1` which results in `2`.
* The outer `yield 2` is encountered; execution pauses and yields `{ value: 2, done: false }`.
* Logs **`2`**.

1. **`console.log(generator.next(1).value)` $\rightarrow$ `undefined**`

* Resumes the generator at the outer `yield`.
* There are no more statements, so the function reaches an implicit return (`return undefined`).
* The generator completes, returning `{ value: undefined, done: true }`.
* Logs **`undefined`**.
