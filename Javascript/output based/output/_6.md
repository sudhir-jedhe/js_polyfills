const promise = Promise.resolve()
function f() {
  return promise
}

async function a() { return f() }
async function b() { return await f() }
function c() { return f() }

console.log(a() === b())
console.log(b() === c())
console.log(a() === c())

**Output:**

```javascript
false
false
false

```

---

**Step-by-Step Breakdown:**

1. **`async` Functions Always Return a New Promise:**

* An `async` function (`a` and `b`) **always** wraps its return value in a **newly created Promise instance** per invocation, even if the value returned is already a Promise.
* `a()` creates and returns a brand-new Promise (Promise A).
* `b()` creates and returns a brand-new Promise (Promise B).

1. **Standard Functions (`c`) Return the Direct Reference:**

* `c()` is a regular synchronous function. It simply returns the existing global reference: `promise`.

1. **Comparisons:**

* **`a() === b()` $\rightarrow$ `false`:** Two distinct Promise instances created by separate async function executions.
* **`b() === c()` $\rightarrow$ `false`:** A new Promise instance returned by `b()` compared against the original `promise` reference returned by `c()`.
* **`a() === c()` $\rightarrow$ `false`:** A new Promise instance returned by `a()` compared against the original `promise` reference returned by `c()`.
