```js
const promise = Promise.resolve()
function f() {
  return promise
}

async function a() { return f() }
async function b() { return await f() }
function c() { return f() }

console.log(a() === b())
console.log(b() === c())
console.log(a() === c())
```

**Output:**

```javascript
false
false
false

```

---

### Step-by-Step Breakdown

**Core Rule (`async` Function Return Values):**

* Every call to an `async` function implicitly wraps the execution and returns a **brand new `Promise` instance** representing the completion of that async invocation, even if the value returned from inside the function is already a resolved promise.
* A standard, non-`async` function returns whatever reference it explicitly evaluates without creating a new wrapper.

---

1. **`c()`:**

* `c` is a normal function returning the result of `f()`.
* `c()` returns the exact reference to `promise`.

1. **`a()`:**

* `a` is an `async` function.
* Invoking `a()` creates and returns a **new Promise** (let's call it $P_1$) that eventually resolves with the resolution of `f()`.

1. **`b()`:**

* `b` is an `async` function.
* Invoking `b()` creates and returns another **distinct, new Promise** (let's call it $P_2$) that resolves after awaiting `f()`.

1. **Comparisons:**

* `a() === b()` $\rightarrow$ Compares two newly allocated, distinct promise objects ($P_1 \neq P_2$) $\rightarrow$ **`false`**.
* `b() === c()` $\rightarrow$ Compares a newly allocated promise instance with the original `promise` reference ($P_2 \neq \text{promise}$) $\rightarrow$ **`false`**.
* `a() === c()` $\rightarrow$ Compares a newly allocated promise instance with the original `promise` reference ($P_1 \neq \text{promise}$) $\rightarrow$ **`false`**.
