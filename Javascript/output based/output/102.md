# File 102

```js
class Site {
  name = 'BFE'
  getHandle() {
    return {
      name: 'bigfrontend',
      getName1() {
        return this.name
      },
      getName2: () => {
        return this.name
      },
      getName3: function() {
        return this.name
      }
    }
  }
}

const site = new Site()
console.log(site.getHandle().getName1())
console.log(site.getHandle().getName2())
console.log(site.getHandle().getName3())

```

**Output:**

```javascript
"bigfrontend"
"BFE"
"bigfrontend"

```

---

### Step-by-Step Breakdown

**Core Rules (`this` in Methods vs. Arrow Functions):**

* **Standard Methods / Functions (`getName1` & `getName3`):** When invoked as a method of an object (`obj.method()`), `this` is dynamically bound to the object directly preceding the dot (the returned object `{ name: 'bigfrontend', ... }`).
* **Arrow Functions (`getName2`):** Arrow functions do not have their own `this` binding; they lexically capture `this` from their enclosing execution context at creation time.

---

1. **`site.getHandle().getName1()` $\rightarrow$ `"bigfrontend"**`

* Invoked on the returned object literal.
* `this` points to the object literal itself $\rightarrow$ reads `this.name` $\rightarrow$ **`"bigfrontend"`**.

1. **`site.getHandle().getName2()` $\rightarrow$ `"BFE"**`

* Defined as an arrow function inside `getHandle()`.
* When `site.getHandle()` was called, the execution context's `this` was the `site` instance.
* The arrow function lexically captures `this` as `site` $\rightarrow$ reads `site.name` $\rightarrow$ **`"BFE"`**.

1. **`site.getHandle().getName3()` $\rightarrow$ `"bigfrontend"**`

* Standard function expression invoked on the returned object literal.
* `this` points to the object literal $\rightarrow$ reads `this.name` $\rightarrow$ **`"bigfrontend"`**.
