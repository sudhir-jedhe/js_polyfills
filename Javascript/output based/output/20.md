### Step-by-Step Breakdown

1. **Named Function Expressions & Scope of `d`:**

* In `const c = function d() { ... }`, `d` is a **Named Function Expression (NFE)**.
* The identifier `d` is scoped **only inside the function body itself** (for recursion or self-reference) and is never bound in the outer scope.
* Inside the function body, the binding `d` is **read-only / immutable** (similar to a `const` declaration).

1. **Outer Scope Checks:**

* `console.log(typeof a)` $\rightarrow$ **`"function"`** (standard function declaration).
* `console.log(typeof b)` $\rightarrow$ **`"function"`** (function expression assigned to `b`).
* `console.log(typeof c)` $\rightarrow$ **`"function"`** (function expression assigned to `c`).
* `console.log(typeof d)` $\rightarrow$ **`"undefined"`** (`d` does not exist in the outer scope).

1. **Executing `c()`:**

* `console.log(typeof d)` inside `c`: Refers to the inner NFE binding $\rightarrow$ logs **`"function"`**.
* `d = 'e'`: Attempting to reassign the immutable NFE identifier fails silently in non-strict mode (or throws a `TypeError` in strict mode).
* `console.log(typeof d)` inside `c`: `d` remains unchanged $\rightarrow$ logs **`"function"`**.
