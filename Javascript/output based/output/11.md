### Step-by-Step Breakdown

**Addition (`+` operator with arrays/objects):**
The `+` operator triggers `ToPrimitive()`, which for Arrays calls `.toString()` (equivalent to `.join(',')`):

* **`[] + []` $\rightarrow$ `"" + ""` $\rightarrow$ `""**` (empty string)
* **`[] + 1` $\rightarrow$ `"" + 1` $\rightarrow$ `"1"**`
* **`[[]] + 1` $\rightarrow$ `"" + 1` $\rightarrow$ `"1"**` (an array containing an empty array flattens to `""`)
* **`[[1]] + 1` $\rightarrow$ `"1" + 1` $\rightarrow$ `"11"**`
* **`[[[[2]]]] + 1` $\rightarrow$ `"2" + 1` $\rightarrow$ `"21"**`
* **`[] + {}` $\rightarrow$ `"" + "[object Object]"` $\rightarrow$ `"[object Object]"**`
* **`{} + {}` $\rightarrow$ `"[object Object]" + "[object Object]"` $\rightarrow$ `"[object Object][object Object]"**` *(when evaluated as an expression inside `console.log()`)*

**Subtraction (`-` operator):**
The `-` operator forces numeric coercion via `ToNumber()` on both sides:

* **`[] - 1` $\rightarrow$ `Number("") - 1` $\rightarrow$ `0 - 1` $\rightarrow$ `-1**`
* **`[[]] - 1` $\rightarrow$ `Number("") - 1` $\rightarrow$ `0 - 1` $\rightarrow$ `-1**`
* **`[[1]] - 1` $\rightarrow$ `Number("1") - 1` $\rightarrow$ `1 - 1` $\rightarrow$ `0**`
* **`[[[[2]]]] - 1` $\rightarrow$ `Number("2") - 1` $\rightarrow$ `2 - 1` $\rightarrow$ `1**`
* **`{} - {}` $\rightarrow$ `Number("[object Object]") - Number("[object Object]")` $\rightarrow$ `NaN - NaN` $\rightarrow$ `NaN**`
