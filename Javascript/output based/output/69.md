**Core Rule (`Function.prototype.length`):**

* A function's `length` property indicates the **number of formal parameters** declared before the first parameter with a default value.
* Rest parameters (`...rest`) and parameters with default values do not contribute to the count.

1. **Evaluating `foo.length`:**
