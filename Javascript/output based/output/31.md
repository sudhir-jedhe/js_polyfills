### Step-by-Step Breakdown

**Arithmetic Rules with `Infinity` (IEEE 754 standard):**

* `number / 0` $\rightarrow$ `Infinity` (or `-Infinity` if negative).
* `0 / 0` $\rightarrow$ `NaN` (indeterminate form).
* `Infinity * 0` or `0 * Infinity` $\rightarrow$ `NaN`.
* `Infinity + Infinity` $\rightarrow$ `Infinity`.
* `Infinity - Infinity` $\rightarrow$ `NaN` (indeterminate form).
* `Infinity * Infinity` $\rightarrow$ `Infinity`.
* `Infinity / Infinity` $\rightarrow$ `NaN` (indeterminate form).
* `0 / Infinity` $\rightarrow$ `0`.
