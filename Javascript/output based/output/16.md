### Step-by-Step Breakdown

**Core Rules:**

* **`typeof null`**: Returns `"object"` due to a historic JavaScript implementation quirk where type tags for objects were represented with zeros, matching `null`'s null pointer.
* **`instanceof` Operator**: Checks if `Constructor.prototype` exists anywhere in the operand's prototype chain.
* **Primitives** (e.g., `1`, `true`, `null`, `Number(1)`) are not object instances and do not possess a prototype chain for `instanceof` to traverse; `instanceof` always returns `false` for primitives.
* **Object Wrappers** created with `new` (e.g., `new Number(1)`, `new Boolean(true)`) create full object instances inheriting from their constructor's prototype and `Object.prototype`.

---

1. **`typeof null` $\rightarrow$ `"object"**`

* Legacy behavior in the JavaScript specification.

1. **`null instanceof Object` $\rightarrow$ `false**`

* `null` has no prototype chain.

1. **`typeof 1` $\rightarrow$ `"number"**`

* Primitive number type check.

1. **`1 instanceof Number` $\rightarrow$ `false**`

* `1` is a primitive value, not an object instance created from `Number`.

1. **`1 instanceof Object` $\rightarrow$ `false**`

* `1` is a primitive value.

1. **`Number(1) instanceof Object` $\rightarrow$ `false**`

* Calling `Number(...)` as a function performs type coercion and returns a primitive number `1`.

1. **`new Number(1) instanceof Object` $\rightarrow$ `true**`

* `new Number(1)` creates an explicit Number wrapper object, which inherits from `Object.prototype`.

1. **`typeof true` $\rightarrow$ `"boolean"**`

* Primitive boolean type check.

1. **`true instanceof Boolean` $\rightarrow$ `false**`

* `true` is a primitive boolean.

 1. **`true instanceof Object` $\rightarrow$ `false**`

* `true` is a primitive boolean.

 1. **`Boolean(true) instanceof Object` $\rightarrow$ `false**`

* Calling `Boolean(...)` as a function performs type conversion and returns a primitive `true`.

 1. **`new Boolean(true) instanceof Object` $\rightarrow$ `true**`

* `new Boolean(true)` creates an explicit Boolean wrapper object, inheriting from `Object.prototype`.

 1. **`[] instanceof Array` $\rightarrow$ `true**`

* Array literal `[]` creates an Array instance whose prototype is `Array.prototype`.

 1. **`[] instanceof Object` $\rightarrow$ `true**`

* `Array.prototype` inherits from `Object.prototype` in the prototype chain.

 1. **`(() => {}) instanceof Object` $\rightarrow$ `true**`

* Functions in JavaScript are objects; `Function.prototype` inherits from `Object.prototype`.
