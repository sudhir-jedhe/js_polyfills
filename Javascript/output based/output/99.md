### Step-by-Step Breakdown

**Core Rule (Lexical Scoping & Closures):**

* JavaScript uses **lexical (static) scoping**, meaning variable resolution is determined by where functions are written in the source code, not where they are executed.
* An inner function retains access to the variables declared in its enclosing lexical parent scope (forming a closure).

---

1. `function a()` declares a local variable `let dev = 'BFE'`.
2. The anonymous function returned by `a()` is lexically enclosed by `a()`'s scope, capturing the local `dev = 'BFE'`.
3. Changing the outer global variable `dev = 'bigfrontend'` has no effect on the local `dev` inside `a()`.
4. Calling `a()()` executes the returned closure:

* It resolves `dev` from its immediate parent scope (`a()`).
* Logs **`"BFE"`**.
