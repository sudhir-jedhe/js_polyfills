# File 73

```js

// This is a JavaScript Quiz from BFE.dev

var a = 1;
(function() {
  console.log(a + this.a);
  var a = '2'
  console.log(a + this.a);
})();

var name = 1;
(function() {
  console.log(name + this.name);
  var name = '2'
  console.log(name + this.name);
})();
```

**Output:**

```javascript
NaN
"21"
"undefined1"
"21"

```

---

### Step-by-Step Breakdown

**Core Concepts:**

1. **Variable Hoisting:** Variables declared with `var` inside a function are hoisted to the top of that function's scope and initialized to `undefined`.
2. **`this` Binding in IIFEs:** In non-strict mode, an immediately invoked function expression (IIFE) has `this` bound to the global object (`window`).
3. **The `window.name` Quirk:** In browser environments, `window.name` is a built-in property with a getter/setter that automatically coerces any value assigned to it into a **string** (`String(1) -> "1"`).

---

1. **First IIFE (`a`):**

* Globally, `var a = 1` sets `window.a = 1` (number).
* Inside the IIFE, local `var a` is hoisted and starts as `undefined`.
* `console.log(a + this.a)` $\rightarrow$ `undefined + 1` evaluates to **`NaN`**.
* `a = '2'` assigns the local variable to the string `'2'`.
* `console.log(a + this.a)` $\rightarrow$ `'2' + 1` evaluates to **`"21"`**.

1. **Second IIFE (`name`):**

* Globally, `var name = 1` sets `window.name = "1"` (coerced to a string).
* Inside the IIFE, local `var name` is hoisted and starts as `undefined`.
* `console.log(name + this.name)` $\rightarrow$ `undefined + "1"` triggers string concatenation, evaluating to **`"undefined1"`**.
* `name = '2'` assigns the local variable to the string `'2'`.
* `console.log(name + this.name)` $\rightarrow$ `'2' + "1"` evaluates to **`"21"`**.
