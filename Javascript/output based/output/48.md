# File 48

```js
// This is a JavaScript Quiz from BFE.dev

function Foo() { }
Foo.prototype.bar = 1
const a = new Foo()
console.log(a.bar)

Foo.prototype.bar = 2
const b = new Foo()
console.log(a.bar)
console.log(b.bar)

Foo.prototype = {bar: 3}
const c = new Foo()
console.log(a.bar)
console.log(b.bar)
console.log(c.bar)
```

**Output:**

```javascript
1
2
2
2
2
3

```

---

### Step-by-Step Breakdown

**Core Concept:**

* When an object is created with `new Foo()`, its internal prototype (`[[Prototype]]` / `__proto__`) is set to the **current object referenced by `Foo.prototype**`.
* **Mutating** a property on the prototype object (`Foo.prototype.bar = 2`) affects all existing and future instances pointing to that prototype.
* **Reassigning** `Foo.prototype` to a completely new object (`Foo.prototype = { bar: 3 }`) does **not** update previously created instances; they still reference the original prototype object in memory.

---

1. **First Block:**

* `Foo.prototype.bar = 1`
* `const a = new Foo()` creates instance `a`, referencing Prototype Object 1.
* `console.log(a.bar)` $\rightarrow$ **`1`**

1. **Second Block:**

* `Foo.prototype.bar = 2` mutates Prototype Object 1 in place.
* `const b = new Foo()` creates instance `b`, also referencing Prototype Object 1.
* `console.log(a.bar)` $\rightarrow$ **`2`**
* `console.log(b.bar)` $\rightarrow$ **`2`**

1. **Third Block:**

* `Foo.prototype = { bar: 3 }` creates a brand new Prototype Object 2.
* `const c = new Foo()` creates instance `c`, referencing Prototype Object 2.
* `a` and `b` still point to Prototype Object 1 (where `bar` is `2`).
* `console.log(a.bar)` $\rightarrow$ **`2`**
* `console.log(b.bar)` $\rightarrow$ **`2`**
* `console.log(c.bar)` $\rightarrow$ **`3`**
