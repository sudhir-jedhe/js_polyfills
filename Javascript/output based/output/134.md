const items = [
  {
    id: 'a'
  },
  {
    id: 'b'
  },
]
const groups = Object.groupBy(items, ({id}) => id)
console.log(items.toString())
console.log(groups.toString())

**Output:**

```javascript
[object Object],[object Object]
TypeError: groups.toString is not a function

```

---

**Step-by-Step Breakdown:**

1. **`items.toString()` $\rightarrow$ `"[object Object],[object Object]"**`

* `items` is a standard JavaScript array containing two objects.
* `Array.prototype.toString()` calls `.join(',')` on its elements, which implicitly converts each plain object by calling `Object.prototype.toString()`, resulting in `"[object Object],[object Object]"`.

1. **`groups.toString()` $\rightarrow$ `TypeError: groups.toString is not a function**`

* `Object.groupBy()` creates a **null-prototype object** (`Object.create(null)`).
* Because it does not inherit from `Object.prototype`, standard prototype methods like `.toString()`, `.hasOwnProperty()`, or `.valueOf()` **do not exist** on `groups`.
* Attempting to call `groups.toString()` throws an uncaught `TypeError`.

---

**Workaround to stringify a null-prototype object:**

```javascript
// Use Object.prototype.toString explicitly:
console.log(Object.prototype.toString.call(groups)); // "[object Object]"

// Or JSON serialize:
console.log(JSON.stringify(groups)); // '{"a":[{"id":"a"}],"b":[{"id":"b"}]}'

```
