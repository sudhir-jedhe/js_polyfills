# File 117

```js
class A {
  static dev = 'BFE'
  dev = 'bigfrontend'
}

class B extends A {
  log() {
    console.log(this.dev)
  }

  static log() {
    console.log(this.dev)
  }
}

B.log()
new B().log()

```

**Output:**

```javascript
"BFE"
"bigfrontend"

```

---

### Step-by-Step Breakdown

**Core Rules (Static vs. Instance Inheritance in ES6 Classes):**

1. **Static Inheritance:** In class inheritance (`class B extends A`), the derived constructor function `B` inherits directly from the base constructor function `A` via `Object.setPrototypeOf(B, A)`. Thus, static properties on `A` are accessible on `B`.
2. **`this` Binding in Static Methods:** Inside a static method invoked as `B.log()`, `this` refers to the class constructor `B` itself.
3. **Instance Inheritance:** Instances created with `new B()` inherit instance fields from `A` (initialized during construction). Inside an instance method invoked as `b.log()`, `this` refers to the instance `b`.

---

1. **`B.log()`:**

* Invoked statically on the class `B`, so `this` is the constructor function `B`.
* JavaScript looks for property `dev` on `B`.
* Since `dev` is not defined directly on `B`, it traverses the constructor prototype chain: `B.[[Prototype]] === A`.
* Finds static field `A.dev = 'BFE'`.
* Logs **`"BFE"`**.

1. **`new B().log()`:**

* Creates an instance `b` of class `B`.
* Calling `super()` implicitly initializes instance field `dev = 'bigfrontend'` on `b`.
* Invokes instance method `log()`, where `this` is the instance `b`.
* Looks up `this.dev` directly on instance `b`, which yields `'bigfrontend'`.
* Logs **`"bigfrontend"`**.
