### Step-by-Step Breakdown

**Core Rule (Annex B.3.3 — Block-Scoped Functions in Non-Strict Mode):**

* When a function declaration is inside a block (`if`, `for`, `{}`):

1. A variable binding with the function's name is hoisted to the top of the enclosing function/closure scope as `var`, initialized to **`undefined`**.
2. Inside the block itself, the function is fully hoisted within that block's local scope.
3. The hoisted function/closure variable only gets assigned the function instance when the execution flow actually enters and executes the block.

---

1. **First Snippet $\rightarrow$ `"2"**`

* Inside the IIFE, a local `fn` binding is hoisted to the function scope and initialized to `undefined` (shadowing the outer global `fn`).
* `if (!fn)` evaluates `!undefined` $\rightarrow$ `true`.
* The block executes, assigning the function definition to the local `fn`.
* `fn()` executes and logs: **`"2"`**.

1. **Second Snippet $\rightarrow$ `"4"**`

* The local block declaration hoists a local `fn1 = undefined` to the top of the IIFE.
* This shadows the outer `function fn1() { console.log('3') }`.
* `if (!fn1)` evaluates `!undefined` $\rightarrow$ `true`.
* The block executes and binds the new function logging `'4'`.
* `fn1()` executes and logs: **`"4"`**.

1. **Third Snippet $\rightarrow$ `TypeError: fn3 is not a function**`

* A local variable `fn3` is hoisted and initialized to `undefined`.
* Because the condition is `if (false)`, the block is never entered, leaving `fn3` as `undefined`.
* Calling `fn3()` is equivalent to calling `undefined()`, which throws **`Uncaught TypeError: fn3 is not a function`**.
