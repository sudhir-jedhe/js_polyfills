# File 55

```js
// This is a JavaScript Quiz from BFE.dev


const arr = [1,,,2]

// forEach
arr.forEach(i => console.log(i))

// map
console.log(arr.map(i => i * 2))

// for ... of
for (const i of arr) {
  console.log(i)
}

// spread
console.log([...arr])
```

**Output:**

```javascript
1
2
[2, empty × 2, 4]
1
undefined
undefined
2
[1, undefined, undefined, 2]

```

*(Note: Depending on the JS runtime console, `[2, empty × 2, 4]` may also be displayed as `[2, <2 empty items>, 4]` or `[2, , , 4]`)*

---

### Step-by-Step Breakdown

**Core Concept (Sparse Arrays & "Holes" vs. `undefined`):**

* `[1,,,2]` creates a **sparse array** of `length: 4`.
* Index `0`: `1`
* Index `1`: *hole / empty* (property does not exist)
* Index `2`: *hole / empty* (property does not exist)
* Index `3`: `2`

* **Array Methods (`forEach`, `map`, `filter`, etc.):** Iterate based on own property keys (`hasOwnProperty`) and **skip missing slots/holes** entirely.
* **Iterator Protocol (`for...of`, spread `[...]`, `Array.from`):** Iterates over all indices from `0` to `length - 1` by reading `arr[index]`. Accessing a missing index returns **`undefined`**, converting holes into explicit `undefined` values.

---

1. **`arr.forEach(i => console.log(i))`**

* Skips empty slots at indices `1` and `2`.
* Only calls the callback for indices `0` and `3`.
* Logs:

```javascript
1
2

```

1. **`console.log(arr.map(i => i * 2))`**

* Callback runs only for indices `0` and `3`.
* The returned array preserves holes at indices `1` and `2`.
* Logs: `[2, <2 empty items>, 4]`.

1. **`for (const i of arr) { console.log(i) }`**

* Uses `arr[Symbol.iterator]()`, visiting every index from `0` to `3`.
* Accessing indices `1` and `2` yields `undefined`.
* Logs:

```javascript
1
undefined
undefined
2

```

1. **`console.log([...arr])`**

* Spread consumes the iterator protocol, reading each element sequentially.
* Holes are converted into real elements holding `undefined`.
* Logs: `[1, undefined, undefined, 2]`.
