# File 28

```js
// This is a JavaScript Quiz from BFE.dev

const func1 = () => console.log(1)

func1()

func2()

function func2() {
  console.log(2)
}


func3()

var func3 = function func4() {
  console.log(3)
}
```

**Output:**

```javascript
1
2
// Uncaught TypeError: func3 is not a function

```

---

### Step-by-Step Breakdown

1. **`func1()` $\rightarrow$ logs `1**`

* `func1` is declared as an arrow function with `const` and initialized before its invocation, so it executes normally.

1. **`func2()` $\rightarrow$ logs `2**`

* `function func2() { ... }` is a **function declaration**.
* In JavaScript, function declarations are hoisted completely (both the identifier and its implementation) to the top of the scope, allowing them to be safely called before their definition in the code.

1. **`func3()` $\rightarrow$ `TypeError: func3 is not a function**`

* `var func3 = function func4() { ... }` is a **function expression assigned to a `var**`.
* Only the variable declaration `var func3` is hoisted, initialized to `undefined`. The assignment of the function does not happen until that line executes.
* Calling `undefined()` results in a runtime `TypeError`.
