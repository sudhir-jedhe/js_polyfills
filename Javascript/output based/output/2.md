// This is a JavaScript Quiz from BFE.dev

new Promise((resolve, reject) => {
  resolve(1)
  resolve(2)
  reject('error')
}).then((value) => {
  console.log(value)
}, (error) => {
  console.log('error')
})

**Output:**

```javascript
1

```

---

**Step-by-Step Breakdown:**

1. **Promise State Immutability:** A Promise can only settle once. Its state transitions permanently from `pending` to either `fulfilled` or `rejected`.
2. **First Settling Action Wins:**

* `resolve(1)` sets the state to **fulfilled** with the value `1`.
* Subsequent calls to `resolve(2)` and `reject('error')` are silently ignored.

1. **Fulfillment Handler Runs:**

* The first callback (`onFulfilled`) passed to `.then()` is queued as a microtask with the resolved value `1`.
* `console.log(value)` executes and logs `1`.

**Output:**

```javascript
1

```

---

### Step-by-Step Event Loop Lifecycle

```
========================================================================================
PHASE 1: SYNCHRONOUS EXECUTION (Call Stack)
========================================================================================
1. new Promise(executor) constructor runs synchronously on the Call Stack:
   - resolve(1) is called:
     * Transitions Promise state: 'pending' -> 'fulfilled'
     * Sets internal Promise value to: 1
   - resolve(2) is called:
     * Ignored. Promise is already settled and immutable.
   - reject('error') is called:
     * Ignored. Promise is already settled.
2. .then(onFulfilled, onRejected) is attached:
   - Because the promise is already 'fulfilled', the onFulfilled handler is scheduled.
   - Pushes `(value) => { console.log(value) }` with value = 1 into the Microtask Queue.
3. Synchronous execution completes. The Call Stack is now empty.

[Call Stack]: (Empty)
[Microtask Queue]: [ Task 1: onFulfilled(1) ]
[Macrotask Queue]: (Empty)
========================================================================================

========================================================================================
PHASE 2: MICROTASK PROCESSING (Queue Draining)
========================================================================================

--- Microtask Tick 1 ---
* Call Stack dequeues and runs Task 1:
  - console.log(value) runs with value = 1
  - Logs: 1
* Microtask Queue is completely drained. Execution completes.

[Microtask Queue]: (Empty)
========================================================================================

```

---

### Key Concepts

* **Promise Settling Immutability:** A Promise can only undergo a state transition once (`pending` $\rightarrow$ `fulfilled` or `pending` $\rightarrow$ `rejected`). Any subsequent `resolve()` or `reject()` invocations inside the same executor function are ignored.
* **Fulfillment Route:** Since `resolve(1)` was the first settling trigger, only the `onFulfilled` handler is scheduled into the Microtask Queue; the `onRejected` handler is never reached.
