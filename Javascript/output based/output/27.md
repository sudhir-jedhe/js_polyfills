```js
// This is a JavaScript Quiz from BFE.dev

const a = 1
console.log(a)

var b
console.log(b)
b = 2

console.log(c)
var c = 3

console.log(d)
let d = 2
```

**Output:**

```javascript
1
undefined
undefined
// Uncaught ReferenceError: Cannot access 'd' before initialization

```

---

### Step-by-Step Breakdown

1. **`const a = 1; console.log(a)` $\rightarrow$ `1**`

* Variable `a` is declared and initialized with `1`, then printed.

1. **`var b; console.log(b); b = 2` $\rightarrow$ `undefined**`

* `var b` is hoisted and automatically initialized with `undefined`.
* Logging `b` prints `undefined` before it is assigned `2`.

1. **`console.log(c); var c = 3` $\rightarrow$ `undefined**`

* The declaration `var c` is hoisted to the top of the scope and initialized with `undefined`.
* At the time `console.log(c)` executes, the assignment (`c = 3`) has not yet run, so it prints `undefined`.

1. **`console.log(d); let d = 2` $\rightarrow$ `ReferenceError**`

* `let` and `const` variables are hoisted, but they remain **uninitialized** in the **Temporal Dead Zone (TDZ)** from the start of the block until their declaration line is executed.
* Attempting to read `d` before its declaration throws `ReferenceError: Cannot access 'd' before initialization`.
