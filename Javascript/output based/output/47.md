```js
  console.log(2)
}, 10)

  console.log(3)
}, 0);

new Promise((_, reject) => {
  console.log(4)
  reject(5)
  console.log(6)
}).then(() => console.log(7))
.catch(() => console.log(8))
.then(() => console.log(9))
.catch(() => console.log(10))
.then(() => console.log(11))
.then(console.log)
.finally(() => console.log(12))

console.log(13) 
```

### Step-by-Step Breakdown

1. **Synchronous Execution:**

* `console.log(1)` logs **`1`**.
* `setTimeout(..., 10)` schedules a timer macrotask (10ms).
* `setTimeout(..., 0)` schedules a timer macrotask (0ms).
* The `Promise` constructor executor runs synchronously:
* `console.log(4)` logs **`4`**.
* `reject(5)` transitions the promise state to *rejected*.
* `console.log(6)` logs **`6`**.

* The promise chain is configured, and the first rejection handler `.catch()` is enqueued into the **Microtask Queue**.
* `console.log(13)` logs **`13`**.

1. **Microtask Queue Processing:**

* `.catch(() => console.log(8))` runs because the promise was rejected: logs **`8`** and resolves to `undefined`.
* `.then(() => console.log(9))` handles the resolved value: logs **`9`** and resolves to `undefined`.
* `.catch(() => console.log(10))` is skipped because the promise chain is now in a fulfilled state.
* `.then(() => console.log(11))` runs: logs **`11`** and resolves to `undefined`.
* `.then(console.log)` receives `undefined` from the previous `.then()` and logs **`undefined`**.
* `.finally(() => console.log(12))` runs: logs **`12`**.

1. **Macrotask Queue Processing:**

* `setTimeout(..., 0)` callback executes first: logs **`3`**.
* `setTimeout(..., 10)` callback executes after its delay: logs **`2`**.
