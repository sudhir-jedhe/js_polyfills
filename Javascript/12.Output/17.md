### Code Snippet

```javascript
console.log(7 == 7);
console.log(7 == 7 == 7);
console.log(7 == 7 == 7 == 0);

```

---

### Output

```text
true
false
true

```

---

### Why this happens

Equality operators (`==`) are evaluated with **left-to-right associativity** and involve **type coercion**:

1. **`7 == 7`**

* Straightforward numeric comparison $\rightarrow$ **`true`**.

1. **`7 == 7 == 7`**

* First step: `(7 == 7)` evaluates to `true`.
* Second step: `true == 7`.
* Loose equality converts boolean `true` to the number `1` (`1 == 7`), which evaluates to **`false`**.

1. **`7 == 7 == 7 == 0`**

* From the previous step, `(7 == 7 == 7)` resolves to `false`.
* Next step: `false == 0`.
* Loose equality converts boolean `false` to the number `0` (`0 == 0`), which evaluates to **`true`**.
