```js
function asyncTask() {
  return new Promise((res) => {
    res();
  });
}

const x = asyncTask()
  .then(() => {
    console.log('First');
  })
  .catch()
  .then(() => {
    console.log('Second');
  });
  ```
  
The output will be:

```text
First
Second

```

---

### Execution Breakdown

1. **`asyncTask()` resolves immediately:** `new Promise((res) => res())` creates a fulfilled promise.
2. **First `.then()` executes:** Logs `'First'`. Since the callback completes without throwing an error, it returns a new promise fulfilled with `undefined`.
3. **`.catch()` is bypassed:** Because the promise was fulfilled (not rejected), the catch block is skipped entirely. Calling `.catch()` without arguments simply passes the fulfilled state down the chain.
4. **Second `.then()` executes:** Receives the fulfilled promise from the chain and logs `'Second'`.
