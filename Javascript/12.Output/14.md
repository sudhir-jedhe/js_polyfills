### Original Code Snippet

```javascript
// Call show function
// without using any ()

function show(){
  console.log('JS is ❤️');
}

```

---

### Solutions (Invoking without `()`)

Here are the most popular JavaScript tricks to invoke a function without using parentheses:

#### 1. Tagged Template Literal (Cleanest & Most Common)

```javascript
show``;

```

#### 2. Using the `new` Keyword

```javascript
new show;

```

#### 3. Defining a Getter

```javascript
Object.defineProperty(globalThis, "run", { get: show });
run;

```

#### 4. Using `Symbol.toPrimitive`, `valueOf`, or `toString` with Type Coercion

```javascript
const obj = { [Symbol.toPrimitive]: show };
+obj; // or `${obj}`

```

#### 5. Custom Iterator Hook

```javascript
const obj = { [Symbol.iterator]: show };
[...obj];

```
