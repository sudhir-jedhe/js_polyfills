**1. Unary `+` & Logical NOT `!**`

```javascript
console.log(+true);
console.log(!"sai");

```

* `+true` converts boolean `true` to a number $\rightarrow$ `1`
* `!"sai"`: Non-empty string `"sai"` is truthy, so negating it $\rightarrow$ `false`
* **Output:**

```text
1
false

```

**2. Loose Equality (`==`) with Arrays & Strings**

```javascript
const x = [1, 2];
const y = '1,2';
console.log(x == y);

```

* `[1, 2]` is converted to a primitive string via `.toString()`, becoming `'1,2'`.
* `'1,2' == '1,2'` evaluates to `true`.
* **Output:**

```text
true

```

**3. Logical OR (`||`) vs. Nullish Coalescing (`??`)**

```javascript
console.log(0 || "Hello");
console.log(0 ?? "Hello");

```

* `0 || "Hello"`: `0` is falsy, so `||` evaluates to the right operand $\rightarrow$ `"Hello"`
* `0 ?? "Hello"`: `??` only falls back on `null` or `undefined`. `0` is defined $\rightarrow$ `0`
* **Output:**

```text
Hello
0

```

---

**4. Chained Comparison Operators**

```javascript
console.log(5 < 8 > 2);
console.log(1 > 19 < 2);

```

* `5 < 8 > 2` $\rightarrow$ `(5 < 8) > 2` $\rightarrow$ `true > 2` $\rightarrow$ `1 > 2` $\rightarrow$ `false`
* `1 > 19 < 2` $\rightarrow$ `(1 > 19) < 2` $\rightarrow$ `false < 2` $\rightarrow$ `0 < 2` $\rightarrow$ `true`
* **Output:**

```text
false
true

```

**5. Array Addition / Coercion (`+`)**

```javascript
console.log([] + []);
console.log([1] + []);
console.log([1] + "abc");

```

* `[] + []` $\rightarrow$ `"" + ""` $\rightarrow$ `""` (empty string)
* `[1] + []` $\rightarrow$ `"1" + ""` $\rightarrow$ `"1"`
* `[1] + "abc"` $\rightarrow$ `"1" + "abc"` $\rightarrow$ `"1abc"`
* **Output:**

```text
""
1
1abc

```

**6. Short-Circuit Evaluation (`||` vs `&&`)**

```javascript
console.log(false || null || "Hello");
console.log(false && null && "Hello");

```

* `false || null || "Hello"`: Skips falsy values (`false`, `null`) and returns the first truthy value $\rightarrow$ `"Hello"`
* `false && null && "Hello"`: Short-circuits at the first falsy operand $\rightarrow$ `false`
* **Output:**

```text
Hello
false

```

**7. Lexicographical vs. Numeric String Comparison**

```javascript
console.log("2" > "10");
console.log("2" > 10);

```

* `"2" > "10"`: Both are strings, so comparison is lexicographical (character-by-character). Char code of `'2'` ($50$) > char code of `'1'` ($49$) $\rightarrow$ `true`
* `"2" > 10`: One operand is a number, so `"2"` coerces to number `2`. $2 > 10$ $\rightarrow$ `false`
* **Output:**

```text
true
false

```

**9. Parallel API Calls (`Promise.all`)**

> *"Let's say I have 3 API calls: `getusers()`, `getorders()`, & `getCart()`. I need to wait until all the 3 API calls are completed and display in dashboard."*

* Use `Promise.all()` (or `Promise.allSettled()` if partial failures should still display):

```javascript
async function loadDashboard() {
  try {
    const [users, orders, cart] = await Promise.all([
      getusers(),
      getorders(),
      getCart()
    ]);
    
    // Display in dashboard
    renderDashboard({ users, orders, cart });
  } catch (error) {
    console.error("Failed to load dashboard data:", error);
  }
}

```

**10. Event Loop Execution Order (Microtasks vs. Macrotasks)**

```javascript
console.log(1);
new Promise((resolve) => {
  console.log(4);
  setTimeout(() => {
    console.log(2);
  });
  resolve();
}).then(() => {
  console.log(5);
  setTimeout(() => {
    console.log(3);
  });
});

```

* **Step-by-step execution:**

1. Synchronous: Logs `1`.
2. Synchronous (inside Promise executor): Logs `4`.
3. `setTimeout` for `2` is scheduled to the **Macrotask Queue**.
4. `resolve()` queues the `.then()` handler to the **Microtask Queue**.
5. Synchronous script ends; process microtasks: `.then()` executes and logs `5`.
6. `setTimeout` for `3` is scheduled to the **Macrotask Queue** (behind `2`).
7. Microtasks empty; process macrotasks: Logs `2`, then logs `3`.

* **Output:**

```text
1
4
5
2
3

```

**10. Three APIs Race/Timing Example**

```javascript
function getUser() {
  return new Promise(resolve => {
    setTimeout(() => resolve('User data loaded'), 1000);
  });
}

function getOrders() {
  return new Promise(resolve => {
    setTimeout(() => resolve('Orders data loaded'), 1500);
  });
}

function getCart() {
  return new Promise(resolve => {
    setTimeout(() => resolve('Cart data loaded'), 500);
  });
}

Promise.race([getUser(), getOrders(), getCart()]).then(data => {
  console.log(data);
});

```

* `getCart()` resolves fastest at $500\text{ms}$.
* **Output:**

```text
Cart data loaded

```
