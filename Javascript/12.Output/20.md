***  20.md ***

### Code Snippet

```javascript
var length = 20;

function count() {
  console.log(this.length);
}

const data = [count, "A", 0];

data[0]("Hey!");

```

---

### Output

```text
3

```

---

### Why this happens

* **Method Invocation on an Array:** In JavaScript, calling `data[0]("Hey!")` is equivalent to invoking the method as `data.0("Hey!")`.
* **Implicit Binding (`this`):** When a function is invoked as a property/element of an object or array, `this` inside that function is automatically bound to the object/array calling it—in this case, the `data` array.
* **Property Access:** Inside `count()`, `this.length` accesses the `.length` property of the `data` array.
* Since `data = [count, "A", 0]`, its length is **`3`**. The outer `var length = 20` is ignored.

### Code Snippet

```javascript
Promise.resolve(() => {
  return "🍊";
}).then((data) => {
  console.log(data);
});

```

---

### Output

```text
[Function (anonymous)]

```

*(or the function definition string `() => { return "🍊"; }` depending on the environment)*

---

### Why this happens

* **`Promise.resolve(value)` does not execute functions:** Unlike the `new Promise(executor)` constructor, `Promise.resolve()` simply wraps whatever value you pass to it into a resolved promise.
* Since an arrow function `() => { return "🍊"; }` was passed directly as the argument, `Promise.resolve` treats that function definition as a plain JavaScript value (object/function reference).
* In the `.then((data) => ...)` callback, `data` receives the **function itself**, not the result of executing it (`"🍊"`).

---

### How to get `"🍊"`

1. **Invoke the function inside `Promise.resolve`:**

```javascript
Promise.resolve((() => {
  return "🍊";
})()).then((data) => {
  console.log(data); // "🍊"
});

```

1. **Or call `data()` in the `.then` handler:**

```javascript
Promise.resolve(() => {
  return "🍊";
}).then((data) => {
  console.log(data()); // "🍊"
});

```

### Code Snippet

```javascript
[1, 2, 3].map(function magicFn(num) {
  return num * num;
});

magicFn();

```

---

### Output

```text
[ 1, 4, 9 ]
ReferenceError: magicFn is not defined

```

---

### Why this happens

* **Named Function Expression (NFE):** When a function is passed as an argument directly into `.map()`, it is treated as a **function expression**, not a top-level **function declaration**.
* **Internal Scope Only:** The name of a named function expression (`magicFn`) is only bound **inside its own function body** (primarily used for recursion or debugging stack traces).
* **Outer Scope Isolation:** `magicFn` is never added to the outer/global scope. Calling `magicFn()` outside the `.map()` callback results in a `ReferenceError`.
