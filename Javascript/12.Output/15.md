### Code Snippet

```javascript
let obj = { lang: 'React' };

const lib = {};
lib.name = obj;

obj = null;

console.log(lib.name);

```

---

### Output

```javascript
{ lang: 'React' }

```

---

### Why this happens

* **Reference by Value:** When `lib.name = obj` executes, `lib.name` receives a copy of the reference pointing to the object `{ lang: 'React' }` in memory. Both `obj` and `lib.name` now point to the exact same memory location.
* **Reassignment vs Mutation:** Setting `obj = null` simply rebinds the variable `obj` to `null`. It does **not** destroy or mutate the underlying `{ lang: 'React' }` object.
* Since `lib.name` still holds a reference to that object, it remains untouched in memory and prints `{ lang: 'React' }`.
