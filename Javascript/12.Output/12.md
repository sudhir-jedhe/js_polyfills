```js
const obj = {};
let key = "constructor";

if (key in obj) {
  console.log('Key Found');
} else {
  console.log('Key Not Found');
}

```

The output will be:

```text
Key Found

```

---

### Why this happens

* The **`in` operator** checks for properties on both the **object itself** and throughout its entire **prototype chain**.
* Plain object literals (`{}`) inherit from `Object.prototype`, which contains a built-in property named `constructor` (pointing to `Object`).
* Therefore, `'constructor' in obj` evaluates to **`true`**.

---

### How to check for own properties only

If the goal is to check whether `'constructor'` was explicitly defined directly on `obj` rather than inherited:

```javascript
// Modern / Safe check:
Object.hasOwn(obj, "constructor"); // false

// Traditional method:
obj.hasOwnProperty("constructor");  // false

```
