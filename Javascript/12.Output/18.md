***  18.md ***

### Code Snippet

```javascript
async function getLion() {
  return "🦁";
}

const lion = getLion();

console.log(lion === "🦁");

```

---

### Output

```text
false

```

---

### Why this happens

* **`async` Functions Always Return a Promise:** Regardless of what you return inside an `async` function (even a plain primitive string like `"🦁"`), JavaScript automatically wraps that value in a resolved `Promise`.
* **Value of `lion`:** `lion` is assigned the Promise object `Promise { <fulfilled>: "🦁" }`, not the unwrapped string `"🦁"`.
* **Strict Equality Check:** Comparing an object (the Promise) to a string primitive (`Promise === "🦁"`) evaluates to **`false`**.

---

### How to get `true`

To access the unwrapped string, you must `await` the function call or resolve the promise using `.then()`:

```javascript
// Using await inside an async context:
const lion = await getLion();
console.log(lion === "🦁"); // true

// Or using .then():
getLion().then((lion) => {
  console.log(lion === "🦁"); // true
});

```
