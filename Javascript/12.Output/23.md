### 3. Asynchronous `useEffect` Callback Anti-Pattern (`9.03.12 PM.png`)

```jsx
useEffect(async () => {
  // callback function
}, []);

```

* **The Problem:** An `async` function implicitly returns a **Promise**.
* In React, `useEffect` requires its return value to be **either a cleanup function or `undefined**`. Returning a Promise confuses React when it tries to run cleanup (`promise()`).
* **Correct Pattern:** Define and call an async function inside the synchronous effect:

```jsx
useEffect(() => {
  const fetchData = async () => {
    // your async code
  };
  fetchData();
}, []);

```

### 4. Default Lexicographical `.sort()` (`10.36.54 PM.png`)

```javascript
const score = [100, 330, 2, 70];
score.sort();
console.log(score);

```

* **Concept:** Without a comparison callback, JavaScript's `.sort()` converts numbers to **strings** and sorts them alphabetically (UTF-16 code units):
* `"100"` comes before `"2"` because character `'1'` < `'2'`.
* `"2"` comes before `"330"` because character `'2'` < `'3'`.
* `"330"` comes before `"70"` because character `'3'` < `'7'`.

* **Output:** `[100, 2, 330, 70]`
* **Numeric Sort Fix:** `score.sort((a, b) => a - b)` $\rightarrow$ `[2, 70, 100, 330]`.

### 5. Chained Loose Equality Evaluations (`10.31.18 PM.png`)


```text
false
true
```
