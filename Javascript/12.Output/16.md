`4 ** 2` and `Math.pow(4, 2)` produce the same numerical result (`16`), but they have two key differences in JavaScript:

---

### Equivalent Code

```javascript
const a = 4 ** 2;
console.log(a); // 16

const b = Math.pow(4, 2);
console.log(b); // 16

```

---

### Key Differences

| Feature                  | Exponentiation Operator (`**`)                                                            | `Math.pow(base, exp)`                         |
| ------------------------ | ----------------------------------------------------------------------------------------- | --------------------------------------------- |
| **BigInt Support**       | ✅ Supported (`2n ** 3n` $\rightarrow$ `8n`)                                               | ❌ Throws `TypeError` on BigInt                |
| **Syntax / Style**       | Infix operator (ES2016 / ES7)                                                             | Standard function call (ES1 / Legacy)         |
| **Precedence Ambiguity** | Requires parentheses with unary minus: `(-4) ** 2` (writing `-4 ** 2` is a `SyntaxError`) | `-Math.pow(4, 2)` works without syntax errors |

---

### Edge Cases to Keep in Mind

* **Unary Negation:**

```javascript
-4 ** 2;         // ❌ SyntaxError: Unary operator used immediately before exponentiation expression
(-4) ** 2;       // ✅ 16
-Math.pow(4, 2); // ✅ -16

```

* **BigInt:**

```javascript
4n ** 2n;         // ✅ 16n
Math.pow(4n, 2n); // ❌ TypeError: Cannot convert a BigInt value to a number

```
