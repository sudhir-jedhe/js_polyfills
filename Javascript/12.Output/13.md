### Code Snippet

```javascript
{
  function show() {
    console.log("Inside Show");
  }
}

show();

```

---

### Output

The result depends on whether the code runs in **Sloppy Mode** or **Strict Mode**:

#### 1. In Sloppy Mode (Default in browser consoles/scripts)

**Output:**

```text
Inside Show

```

* **Why:** Due to legacy web compatibility rules (Annex B of ECMAScript), function declarations inside a block `{}` in sloppy mode are hoisted out of the block scope to the enclosing function/global scope.

#### 2. In Strict Mode (`"use strict"` or ES Modules)

**Output:**

```text
Uncaught ReferenceError: show is not defined

```

* **Why:** In ES6 strict mode, function declarations are strictly **block-scoped** (just like `let` and `const`). `show()` cannot be accessed outside the `{}` braces where it was defined.
