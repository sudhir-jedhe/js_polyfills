 Wrap code in ES Modules, IIFEs (Immediately Invoked Function Expressions), or scoped functions rather than declaring variables globally.

Scoping variables prevents global namespace pollution, avoids naming collisions, and enables proper encapsulation.

**Pattern Comparison**

| Approach                             | Primary Use Case                                    | Encapsulation Mechanism                          |
| ------------------------------------ | --------------------------------------------------- | ------------------------------------------------ |
| **ES Modules (`import` / `export`)** | Modern applications & build tools                   | File-level module scope (Strict Mode by default) |
| **IIFE**                             | Legacy scripts & immediate self-contained execution | Function closure executed at definition          |
| **Block Scope (`let` / `const`)**    | Localized operations & loops                        | Lexical block scope (`{ ... }`)                  |

---

**1. ES Modules (ESM)**

Variables defined inside an ES module do not attach to `window` or `globalThis`. Only explicitly exported entities are accessible externally.

```javascript
// mathUtils.js
const privateMultiplier = 2; // Not accessible outside

export function double(num) {
  return num * privateMultiplier;
}

```

```html
<!-- Consuming in HTML -->
<script type="module" src="./mathUtils.js"></script>

```

**2. IIFE (Immediately Invoked Function Expression)**

Wraps code inside a function expression that executes immediately, trapping all `var`, `let`, and `const` declarations within the function scope.

```javascript
(function () {
  const secretKey = "12345";
  
  function initApp() {
    console.log("App initialized securely without global leak.");
  }

  initApp();
})();

```

**3. Scoped Blocks and Functions**

Use standard block boundaries with `let` and `const` for lightweight execution containment, or standard functions to control execution timing.

```javascript
// Block-scoped sandbox
{
  const tempUser = "Alice";
  let activeSession = true;
  // Variables are garbage-collected once block finishes
}

// Named setup function
function setupAnalytics() {
  const trackerId = "UA-9999";
  // Setup logic here
}
setupAnalytics();

```
