*** copy 2.3.2 Writable false.md ***

`writable: false` makes a specific property of an object **read-only**. Once defined, its value cannot be overwritten with an assignment operator (`=`).

It is configured using `Object.defineProperty()` or `Object.defineProperties()`.

---

**Basic Usage**

```javascript
const user = {};

Object.defineProperty(user, "id", {
  value: 101,
  writable: false,     // Cannot be overwritten
  configurable: true,  // Can still be deleted or reconfigured
  enumerable: true     // Shows up in loops/keys
});

console.log(user.id); // 101

// Attempting to overwrite
user.id = 999; 

console.log(user.id); // 101 (reassignment was ignored)

```

> **Strict Mode Behavior:** In standard non-strict mode, reassigning a `writable: false` property fails silently. In **strict mode** (`"use strict";`), it throws a `TypeError: Cannot assign to read-only property 'id' of object`.

---

**Key Use Cases**

* **Constants on Objects:** Protecting critical metadata (like unique IDs, version numbers, or API endpoints) from accidental modification.
* **Libraries and APIs:** Safeguarding internal framework properties or prototype methods from being overwritten by external code.
* **Targeted Immutability:** Unlike `Object.freeze()` (which locks the *entire* object), `writable: false` lets you freeze specific properties while leaving others mutable:

```javascript
const account = {
  balance: 500
};

// Lock the account number, but leave balance mutable
Object.defineProperty(account, "accountNumber", {
  value: "ACC-987654",
  writable: false
});

account.balance += 100;    // Works! (balance is 600)
account.accountNumber = "ACC-000000"; // Blocked!

```

---

**`writable: false` vs `configurable: false**`

| Descriptor         | What it Controls                  | If set to `false`                                                                |
| ------------------ | --------------------------------- | -------------------------------------------------------------------------------- |
| **`writable`**     | The property's value              | You cannot change the value via assignment (`obj.prop = val`).                   |
| **`configurable`** | The property's setup and deletion | You cannot `delete obj.prop` and cannot modify its property descriptor settings. |

*(Note: If `writable: false` but `configurable: true`, someone can still delete the property or change `writable` back to `true` using `Object.defineProperty`.)*
