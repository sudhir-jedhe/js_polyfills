The difference comes down to how object spread (`{...}`) vs. array/iterable spread (`[...]`) treats `null`.

---

### 1. `{...null}` $\rightarrow$ `{}` (Empty Object)

Object spread relies on the **`CopyDataProperties`** internal algorithm:

* It looks for own, enumerable properties on the target.
* If the value is `null` or `undefined`, it simply ignores it and creates no properties.
* It **does not throw an error**.

```javascript
const obj = { ...null };
console.log(obj); // {}

const merged = { a: 1, ...null, ...undefined, b: 2 };
console.log(merged); // { a: 1, b: 2 }

```

---

### 2. `[...null]` $\rightarrow$ `TypeError` (Throws Exception)

Array spread relies on the **Iteration Protocol (`[Symbol.iterator]`)**:

* It expects the target to be an **iterable** (like an `Array`, `Set`, `Map`, or `String`).
* `null` has no `[Symbol.iterator]` method.
* Because `null` is not iterable, JavaScript immediately throws a runtime error.

```javascript
try {
  const arr = [...null];
} catch (err) {
  console.error(err); // TypeError: null is not iterable (cannot read property Symbol(Symbol.iterator))
}

```

---

### Quick Comparison Table

| Expression       | Evaluates To    | Why?                                                                            |
| ---------------- | --------------- | ------------------------------------------------------------------------------- |
| `{...null}`      | `{}`            | Object spread ignores non-objects and primitive values without enumerable keys. |
| `{...undefined}` | `{}`            | Same rule; ignored gracefully.                                                  |
| `[...null]`      | **`TypeError`** | `null` does not implement `[Symbol.iterator]`.                                  |
| `[...undefined]` | **`TypeError`** | `undefined` does not implement `[Symbol.iterator]`.                             |

---

### Safe Array Handling Pattern

If a value might be `null` or `undefined` and you need to spread it into an array, fall back to an empty array first:

```javascript
const maybeNull = null;

// Safe array spread:
const result = [...(maybeNull || [])];
console.log(result); // []

```
