In functional components, the **lifecycle** is managed through the `useEffect` hook and the component's render cycle, replacing the traditional class methods (`componentDidMount`, `componentDidUpdate`, `componentWillUnmount`).

Every React component progresses through three core phases:

---

**1. Mounting (Creation)**

The component appears on the screen for the first time.

* **Trigger:** Component is first instantiated and rendered into the DOM.
* **Mechanism:** Code inside `useEffect` with an **empty dependency array (`[]`)** executes once after the initial render.
* **Common Use Cases:** Initial API requests, setting up event listeners, WebSocket connections.

```jsx
useEffect(() => {
  console.log("Mounted: Runs once on initial load");
  fetchUserData();
}, []); // Empty dependency array -> runs only on mount

```

---

**2. Updating (Re-rendering)**

The component re-renders in response to data changes.

* **Trigger:** New `props` are received, local `state` changes via a setter function, or parent component re-renders.
* **Mechanism:**
* `useEffect` with **specific dependencies (`[prop, state]`)** runs after renders where any listed value changes.
* `useEffect` with **no dependency array** runs after *every* render.

* **Common Use Cases:** Syncing local state with props, fetching data based on a changed ID parameter, updating document titles.

```jsx
useEffect(() => {
  console.log(`Updated: userId changed to ${userId}`);
  fetchProfile(userId);
}, [userId]); // Runs on mount AND whenever `userId` changes

```

---

**3. Unmounting (Destruction)**

The component is removed from the DOM.

* **Trigger:** Component is conditionally hidden (e.g., `showModal && <Modal/>`) or user navigates to a different route.
* **Mechanism:** Return a **cleanup function** from inside `useEffect`.
* **Common Use Cases:** Canceling pending network requests, clearing timers/intervals (`clearInterval`), unsubscribing from event listeners.

```jsx
useEffect(() => {
  const timer = setInterval(() => {
    console.log("Tick...");
  }, 1000);

  // Cleanup function: runs right before unmount
  return () => {
    console.log("Unmounted: Clearing interval");
    clearInterval(timer);
  };
}, []);

```

---

**Lifecycle vs. `useEffect` Dependency Matrix**

| Lifecycle Event             | Equivalent `useEffect` Pattern            | Runs When                                     |
| --------------------------- | ----------------------------------------- | --------------------------------------------- |
| **Mounting**                | `useEffect(fn, [])`                       | Once after initial paint                      |
| **Updating (Selective)**    | `useEffect(fn, [depA, depB])`             | On mount + when `depA` or `depB` changes      |
| **Updating (Every render)** | `useEffect(fn)`                           | On mount + after every single re-render       |
| **Unmounting**              | `useEffect(() => () => cleanup(), [])`    | Just before the component is destroyed        |
| **Cleanup on Change**       | `useEffect(() => () => cleanup(), [dep])` | Before re-running effect on dependency change |

---

**Complete Lifecycle Example**

```jsx
import React, { useState, useEffect } from "react";

function ChatRoom({ roomId }) {
  const [messages, setMessages] = useState([]);

  useEffect(() => {
    // 1. Mount / Update logic: Connect to the room
    const connection = createConnection(roomId);
    connection.connect();

    // 2. Unmount / Change cleanup: Disconnect from old room
    return () => {
      connection.disconnect();
    };
  }, [roomId]); // Re-subscribes if roomId changes

  return <div>Connected to room: {roomId}</div>;
}

```
