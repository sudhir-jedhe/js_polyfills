`React.memo` uses **shallow comparison** (`Object.is`) to check if props have changed.

Because non-primitive values (objects, arrays, functions) are compared by **reference** rather than content, creating an inline object creates a new memory reference on every parent render. As a result, `Object.is(prevProp, nextProp)` evaluates to `false`, causing the memoized component to re-render.

---

### Key Fixes

* **`useMemo` for Dynamic Objects:** Keep the reference stable across parent renders unless specific dependencies change.

```tsx
const userConfig = useMemo(() => ({ role, theme }), [role, theme]);
return <MemoizedChild config={userConfig} />;

```

* **Static Objects Outside the Component:** Move constant objects outside the component scope so the reference is created only once.

```tsx
const DEFAULT_THEME = { mode: 'dark', size: 'lg' };

function Parent() {
  return <MemoizedChild theme={DEFAULT_THEME} />;
}

```

* **Custom Comparison Function in `React.memo`:** Provide a second argument to manually compare specific fields or perform a deep comparison.

```tsx
export const MemoizedChild = React.memo(Child, (prevProps, nextProps) => {
  return prevProps.config.id === nextProps.config.id;
});

```

* **Flatten Props:** Pass primitive values directly instead of a single wrapping object so `React.memo` compares values instead of references.

```tsx
// Avoid: <Child user={{ id, name }} />
<Child userId={id} userName={name} />

```
