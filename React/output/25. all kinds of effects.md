```js
// This is a React Quiz from BFE.dev 

import * as React from 'react'
import { useState, useEffect, useLayoutEffect, useInsertionEffect} from 'react'
import { createRoot } from 'react-dom/client'

function App() {
  console.log(1)
  const [state, setState] = useState(0)
  useEffect(() => {
    setState(state => state + 1)
  }, [])

  useEffect(() => {
    console.log(2)
    return () => {
      console.log(3)
    }
  }, [state])

  useEffect(() => {
    console.log(4)
    return () => {
      console.log(5)
    }
  }, [state])

  useLayoutEffect(() => {
    console.log(6)
    return () => {
      console.log(7)
    }
  }, [state])

  useInsertionEffect(() => {
    console.log(8)
    return () => {
      console.log(9)
    }
  }, [state])
  console.log(10)
  return null
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)
```

### Step-by-Step Breakdown

**1. Initial Render (`state = 0`)**

* **Render Phase:** `App` executes synchronously from top to bottom:
* Logs **`1`**.
* Registers hook effects in their respective queues.
* Logs **`10`**.

* **Insertion Effects Phase:** `useInsertionEffect` runs synchronously before DOM mutations, logging **`8`**.
* **Layout Effects Phase:** `useLayoutEffect` runs synchronously after DOM mutations but before paint, logging **`6`**.
* **Passive Effects Phase:** `useEffect` callbacks run asynchronously after paint in the order they were declared:
* `setState(state => state + 1)` schedules a re-render with `state = 1`.
* Logs **`2`**.
* Logs **`4`**.

---

**2. Re-render (`state = 1`)**

* **Render Phase:** `App` re-renders with the new state:
* Logs **`1`**.
* Logs **`10`**.

* **Insertion Effects Phase:**
* Previous cleanup runs: logs **`9`**.
* New insertion effect runs: logs **`8`**.

* **Layout Effects Phase:**
* Previous cleanup runs: logs **`7`**.
* New layout effect runs: logs **`6`**.

* **Passive Effects Phase:**
* Cleanups run first in declaration order: logs **`3`**, then **`5`**.
* New effect callbacks run: logs **`2`**, then **`4`**.
