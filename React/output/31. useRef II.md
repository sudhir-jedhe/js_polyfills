*** copy 31. useRef II.md ***

```js
import * as React from 'react'
import { useState, useEffect, useRef} from 'react'
import { createRoot } from 'react-dom/client'

function App() {
  const ref = useRef()
  
  console.log(!!ref.current)
  useEffect(() => {
    console.log(!!ref.current)
  }, [ref.current]) 

  const [state, setState] = useState(0)
  console.log(1)
  
  useEffect(() => {
    console.log(2)
    setState(state => state + 1)
  }, [])

  return <div ref={ref}/>
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)
```

The console will log:

```text
false
1
true
2
true
1

```

### Step-by-Step Execution

1. **Initial Render:**

* `ref` is initialized with `{ current: undefined }`.
* `console.log(!!ref.current)` logs **`false`**.
* `console.log(1)` logs **`1`**.
* React processes JSX and attaches the created `<div>` DOM element to `ref.current`.

1. **Effects after Mount:**

* **First `useEffect`:** Runs on mount. Inside, `ref.current` already points to the DOM node, so `console.log(!!ref.current)` logs **`true`**.
* **Second `useEffect`:** Runs on mount, logs **`2`**, and calls `setState` to increment the state, scheduling a re-render.

1. **Re-render:**

* `ref.current` still holds the DOM node from the initial mount, so `console.log(!!ref.current)` logs **`true`**.
* `console.log(1)` logs **`1`**.

1. **Effects after Re-render:**

* **First `useEffect`:** Does not run because `ref.current` holds the exact same DOM node reference as before (`Object.is` check passes).
* **Second `useEffect`:** Does not run because its dependency array is empty (`[]`).
