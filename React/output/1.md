### Code Snippet

```jsx
import { useEffect } from "react";

let score = 0;

function App() {
  function handleClick() {
    score = score + 10;
  }

  useEffect(() => {
    console.log("Score: ", score);
  }, [score]);

  return <button onClick={handleClick}>Click</button>;
}

```

---

### Output / Behavior

* **On Initial Render:**

```text
Score: 0

```

* **On Clicking the Button:**
* **Nothing logs to the console.**

---

### Why this happens

1. **No Re-render Triggered:** Mutating a regular JavaScript variable (`score = score + 10`) does **not** trigger a React re-render.
2. **`useEffect` only executes during renders:** `useEffect` and its dependency array `[score]` are only evaluated when the component re-renders. Because no re-render occurred, the effect never re-runs on click.

---

### The React Fix (Use `useState`)

To trigger re-renders and re-run effects when the score changes, manage it inside component state:

```jsx
import { useState, useEffect } from "react";

function App() {
  const [score, setScore] = useState(0);

  function handleClick() {
    setScore((prev) => prev + 10);
  }

  useEffect(() => {
    console.log("Score: ", score);
  }, [score]);

  return <button onClick={handleClick}>Click</button>;
}

```
