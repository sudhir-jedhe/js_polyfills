***  28. useEffect() timing III.md ***

```js
'infiniteLoopProtection:false'
import * as React from "react";
import { useState, useEffect } from "react";
import { createRoot } from "react-dom/client";
import { screen, fireEvent } from "@testing-library/dom";

function App() {
  const [state, setState] = useState(0)
  console.log(1)
  
  const start = Date.now()
  while (Date.now() - start < 50) {
    window.timestamp = Date.now()
  }

  useEffect(() => {
    console.log(2)
  }, [state])

  Promise.resolve().then(() => console.log(3))

  setTimeout(() => console.log(4), 0)

  const onClick = () => {
    console.log(5)
    setState(num => num + 1)
    console.log(6)
  }
  return <div>
    <button onClick={onClick}>click me</button>
  </div>
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)

setTimeout(() => fireEvent.click(screen.getByText('click me')), 100)

```

### Step-by-Step Breakdown

**1. Initial Mount Phase**

* **Render:** `App` runs synchronously:
* `console.log(1)` executes and logs **`1`**.
* The synchronous `while` loop blocks the thread for $50\text{ ms}$.
* `useEffect` registers the passive effect callback.
* `Promise.resolve().then(...)` schedules `console.log(3)` onto the **Microtask Queue**.
* `setTimeout(..., 0)` schedules `console.log(4)` onto the **Macrotask Queue**.

* **Microtask Queue:** The JavaScript engine drains all microtasks immediately after synchronous execution ends, logging **`3`**.
* **Passive Effects Phase:** React flushes passive effects via its scheduler task, logging **`2`**.
* **Macrotask Queue:** The 0ms timer callback executes, logging **`4`**.

---

**2. Button Click Phase (at $t = 100\text{ ms}$)**

* `fireEvent.click` executes the event handler synchronously:
* `console.log(5)` logs **`5`**.
* `setState(num => num + 1)` schedules the state update.
* `console.log(6)` logs **`6`**.

* React processes and renders the update:
* `App` re-renders and logs **`1`**.
* Synchronous loop blocks for $50\text{ ms}$.
* New Promise microtask and `setTimeout` macrotask are registered.

* **Microtask Queue:** The Promise resolves first, logging **`3`**.
* **Passive Effects Phase:** The `useEffect` callback runs, logging **`2`**.
* **Macrotask Queue:** The new `setTimeout` timer fires, logging **`4`**.
