***  24. useEffect() timing.md ***

```js
import * as React from "react";
import { useState, useEffect } from "react";
import { createRoot } from "react-dom/client";
import { screen, fireEvent } from "@testing-library/dom";

function App() {
  const [state, setState] = useState(0)
  console.log(1)
  
  useEffect(() => {
    console.log(2)
  }, [state])

  Promise.resolve().then(() => console.log(3))

  setTimeout(() => console.log(4), 0)

  const onClick = () => {
    console.log(5)
    setState(num => num + 1)
    console.log(6)
  }
  return <div>
    <button onClick={onClick}>click me</button>
  </div>
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)

setTimeout(() => fireEvent.click(screen.getByText('click me')), 100)




```

### Step-by-Step Breakdown

**1. Initial Mount Phase**

* **Render:** `App` runs synchronously.
* Logs **`1`**.
* Queues `useEffect` callback (`console.log(2)`).
* Queues microtask `Promise.resolve().then(() => console.log(3))`.
* Queues macrotask `setTimeout(() => console.log(4), 0)`.

* **Microtask Queue:** In React 18, `createRoot` flushes passive effects synchronously during mount. The `useEffect` runs, logging **`2`**.
* The remaining microtask is processed next, logging **`3`**.
* **Macrotask Queue:** The timer callback executes, logging **`4`**.

---

**2. Button Click Phase (at $t = 100\text{ ms}$)**

* `fireEvent.click` fires synchronously:
* Logs **`5`**.
* `setState(num => num + 1)` schedules an update.
* Logs **`6`**.

* `fireEvent` wraps the event dispatch in `act`, which flushes the update immediately:
* **Render:** `App` re-renders with `state = 1`, logging **`1`**.
* Queues new `useEffect`, Promise microtask, and `setTimeout` macrotask.
* **Effects & Microtasks:** Passive effect runs and logs **`2`**, followed by the microtask logging **`3`**.

* **Macrotask Queue:** The newly scheduled `setTimeout` callback executes, logging **`4`**.
