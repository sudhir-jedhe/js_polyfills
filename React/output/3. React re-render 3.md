***  3. React re-render 3.md ***

```js
// This is a React Quiz from BFE.dev 

import * as React from 'react'
import { useState, useEffect } from 'react'
import { createRoot } from 'react-dom/client'

function A({ children }) {
  console.log('A')
  return children
}

function B() {
  console.log('B')
  return <C/>
}

function C() {
  console.log('C')
  return null
}

function D() {
  console.log('D')
  return null
}

function App() {
  const [state, setState] = useState(0)
  useEffect(() => {
    setState(state => state + 1)
  }, [])
  console.log('App')
  return (
    <div>
      <A><B/></A>
      <D/>
    </div>
  )
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)
```

**Output:**

```text
"App"
"A"
"B"
"C"
"D"
"App"
"A"
"B"
"C"
"D"

```

---

### Step-by-Step Breakdown

**Core React Rendering Rules:**

* **JSX Instantiation:** JSX elements written inside a component's body (e.g., `<B/>` inside `App`) are converted to `React.createElement()` calls that run every time the parent component executes.
* **Component-as-Children Optimization Nuance:** The common React performance optimization where `children` skip re-rendering only works if the children were created outside the re-rendering component and passed down as stable props. Here, `<B/>` is created directly inside `App`, so a new element reference is produced on every render of `App`.

---

### Phase 1: Initial Render (`state = 0`)

1. **`App`** renders $\rightarrow$ logs **`"App"`**.
2. **`A`** renders $\rightarrow$ logs **`"A"`**, returning its `children` (`<B/>`).
3. **`B`** renders $\rightarrow$ logs **`"B"`**, returning `<C/>`.
4. **`C`** renders $\rightarrow$ logs **`"C"`**, returning `null`.
5. **`D`** renders $\rightarrow$ logs **`"D"`**, returning `null`.

---

### Phase 2: `useEffect` & State Update (`state = 1`)

1. After mounting, `useEffect` in `App` runs `setState(state => state + 1)`.
2. **`App`** re-renders $\rightarrow$ logs **`"App"`**.
3. During `App`'s execution, fresh element objects are generated for `<A>`, `<B/>`, and `<D/>`.
4. **`A`** re-renders $\rightarrow$ logs **`"A"`**, returning the newly created `<B/>` element.
5. **`B`** re-renders $\rightarrow$ logs **`"B"`**, returning `<C/>`.
6. **`C`** re-renders $\rightarrow$ logs **`"C"`**.
7. **`D`** re-renders $\rightarrow$ logs **`"D"`**.
