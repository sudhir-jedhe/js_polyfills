***  8. Suspense 2.md ***

```js
// This is a React Quiz from BFE.dev 

import * as React from 'react'
import { Suspense } from 'react'
import { createRoot } from 'react-dom/client'

const resource = (() => {
  let data = null
  let status = 'pending'
  let fetcher = null
  return {
    get() {
      if (status === 'ready') {
        return data
      }
      if (status === 'pending') {
        fetcher = new Promise((resolve, reject) => {
          setTimeout(() => {
            data = 1
            status = 'ready'
            resolve()
          }, 100)
        })
        status = 'fetching'
      }

      throw fetcher
    }
  }
})()

function A() {
  console.log('A1')
  const data = resource.get()
  console.log('A2')
  return <p>{data}</p>
}

function B() {
  console.log('B')
  return null
}

function Fallback() {
  console.log('fallback')
  return null
}

function App() {
  console.log('App')
  return <div>
    <Suspense fallback={<Fallback/>}>
      <A/>
      <B/>
    </Suspense>
  </div>
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)
```

```text
"App"
"A1"
"fallback"
"A1"
"A2"
"B"

```

### Step-by-Step Breakdown

**1. Initial Render (Suspension)**

* **`App`** renders first and logs **`"App"`**.
* React enters **`<Suspense>`** and begins rendering its children in order:
* **`A`** starts executing and logs **`"A1"`**.
* `resource.get()` is invoked with `status = 'pending'`, which sets up the timeout and **throws the pending Promise**.
* Because `A` throws, React halts rendering the primary subtree immediately (skipping **`B`** on this pass) and catches the suspension at the boundary.

* React renders the fallback branch: **`Fallback`** executes and logs **`"fallback"`**.

**2. Promise Resolution & Retry**

* After ~100ms, the promise resolves and `status` becomes `'ready'`.
* React retries rendering the suspended primary subtree from the beginning:
* **`A`** renders: logs **`"A1"`**, retrieves the resolved data (`1`), and logs **`"A2"`**.
* React now proceeds to the next child in the tree: **`B`** renders and logs **`"B"`**.
