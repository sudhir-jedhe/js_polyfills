```js
// This is a React Quiz from BFE.dev 

import React, { useEffect, useState } from 'react'
import ReactDOM from 'react-dom'

function App() {
  const [state, setState] = useState(0)
  console.log(state)

  useEffect(() => {
    setState(state => state + 1)
  }, [])

  useEffect(() => {
    console.log(state)
    setTimeout(() => {
      console.log(state)
    }, 100)
  }, [])

  return null
}

ReactDOM.render(<App/>, document.getElementById('root'))
    ```

### Step-by-Step Breakdown

**1. Initial Render (`state = 0`)**

* `App` executes with `state = 0`.
* `console.log(state)` logs **`0`**.

**2. Passive Effects Phase (Mount)**

* **Effect 1** runs: `setState(state => state + 1)` schedules a re-render with `state = 1`.
* **Effect 2** runs (closed over the initial render where `state = 0`):
* `console.log(state)` logs **`0`**.
* `setTimeout` schedules a callback for ~100ms later. Due to closure, this callback holds a reference to the initial `state` value (`0`).

**3. Re-render (`state = 1`)**

* `App` re-renders with `state = 1`.
* `console.log(state)` logs **`1`**.
* Both `useEffect` hooks have empty dependency arrays `[]`, so neither runs on update.

**4. Timeout Execution**

* After 100ms, the timer callback executes.
* Because the function was created inside the mount effect, it reads the captured `state` from that render and logs **`0`** (stale closure).
