*** copy 26. useEffect() III.md ***

```js
import * as React from "react";
import { useState, useEffect } from "react";
import { createRoot } from "react-dom/client";

function App() {
  const [count, setCount] = useState(1)
  console.log(1)
  useEffect(() => {
    console.log(2)
    return () => {
      console.log(3)
    }
  }, [count])

  useEffect(() => {
    console.log(4)
    setCount(count => count + 1)
  }, [])
  return <Child count={count} />
}

function Child({ count }) {
  useEffect(() => {
    console.log(5)
    return () => {
      console.log(6)
    }
  }, [count]);

  return null;
};

const root = createRoot(document.getElementById('root'));
root.render(<App/>)
```

### Step-by-Step Breakdown

**1. Initial Mount Phase (`count = 1`)**

* **Render:**
* **`App`** renders first: logs **`1`**.
* **`Child`** renders.

* **Passive Effects Execution (Child $\to$ Parent):**
* React runs `useEffect` callbacks starting from the leaves up to the root:

1. **`Child`** effect runs: logs **`5`**.
2. **`App`** first effect runs: logs **`2`**.
3. **`App`** second effect runs: logs **`4`** and calls `setCount(count => count + 1)`, scheduling an update to `2`.

---

**2. Re-render Phase (`count = 2`)**

* **Render:**
* **`App`** re-renders: logs **`1`**.
* **`Child`** re-renders with the new prop `count = 2`.

* **Passive Effects Cleanups (Child $\to$ Parent):**
* React runs effect cleanups for updated effects from bottom to top:

1. **`Child`** cleanup runs: logs **`6`**.
2. **`App`** first effect cleanup runs: logs **`3`**.

* **Passive Effects Execution (Child $\to$ Parent):**
* React runs the new effect callbacks from bottom to top:

1. **`Child`** effect runs: logs **`5`**.
2. **`App`** first effect runs: logs **`2`**.
