***  21. useEffect() II.md ***

```js
import * as React from 'react';
import { useState, useRef, useEffect } from 'react';
import { createRoot } from 'react-dom/client';

function App() {
  const [show, setShow] = useState(true)
  return <div>
    {show && <Child unmount={() => setShow(false)} />}
  </div>;
}

function Child({ unmount }) {
  const isMounted = useIsMounted()
  useEffect(() => {
    console.log(isMounted)
    Promise.resolve(true).then(() => {
      console.log(isMounted)
    });
    unmount(); 
  }, []);

  return null;
};

function useIsMounted() {
  const isMounted = useRef(false);

  useEffect(() => {
    isMounted.current = true;
    return () => isMounted.current = false;
  }, []);

  return isMounted.current;
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)
```

### Step-by-Step Breakdown

**1. Initial Render Phase**

* `App` renders with `show = true` and renders `<Child/>`.
* Inside `Child`, the custom hook `useIsMounted()` executes:
* `const isMounted = useRef(false)` initializes `isMounted.current` to `false`.
* `useIsMounted` returns `isMounted.current`, which evaluates to the primitive boolean **`false`**.

* The variable `isMounted` inside `Child` is assigned the primitive value `false`.

**2. Effect Execution Phase**

* `useIsMounted`'s `useEffect` runs and mutates `isMounted.current = true` (this does not affect the primitive variable `isMounted` already captured in `Child`).
* `Child`'s `useEffect` runs:
* `console.log(isMounted)` logs the local primitive variable: **`false`**.
* A microtask is queued via `Promise.resolve(true).then(...)`.
* `unmount()` is called, triggering `setShow(false)` and scheduling an unmount of `Child`.

**3. Microtask Execution**

* The resolved promise callback runs.
* It logs `isMounted` from its closure (the primitive value `false` captured during render), logging **`false`** again.
