```js
// This is a React Quiz from BFE.dev 

import * as React from 'react'
import { useState, useEffect, memo } from 'react'
import { createRoot } from 'react-dom/client'

function A() {
  console.log('A')
  return <B/>
}

const B = memo(() => {
  console.log('B')
  return <C/>
})

function C() {
  console.log('C')
  return null
}

function D() {
  console.log('D')
  return null
}

function App() {
  const [state, setState] = useState(0)
  useEffect(() => {
    setState(state => state + 1)
  }, [])
  console.log('App')
  return (
    <div>
      <A state={state}/>
      <D/>
    </div>
  )
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)

```

**Output:**

```text
"App"
"A"
"B"
"C"
"D"
"App"
"A"
"D"

```

---

### Step-by-Step Breakdown

**Core Rule (`React.memo`):**

* `React.memo` wraps a component and skips re-rendering it if its props remain shallowly equal to the previous render's props.
* When a component's render is skipped by `React.memo`, React also skips rendering its entire child subtree (here, component `C`).

---

### Phase 1: Initial Render (`state = 0`)

1. **`App`** renders $\rightarrow$ logs **`"App"`**.
2. **`A`** renders $\rightarrow$ logs **`"A"`**, returning `<B/>`.
3. **`B`** (memoized) mounts for the first time $\rightarrow$ logs **`"B"`**, returning `<C/>`.
4. **`C`** renders $\rightarrow$ logs **`"C"`**, returning `null`.
5. **`D`** renders $\rightarrow$ logs **`"D"`**, returning `null`.

---

### Phase 2: `useEffect` & State Update (`state = 1`)

1. `useEffect` runs after paint, calling `setState(state => state + 1)`.
2. **`App`** re-renders $\rightarrow$ logs **`"App"`**.
3. **`A`** is not memoized and receives updated `state={1}` $\rightarrow$ logs **`"A"`**, returning `<B/>`.
4. **`B`** is wrapped in `React.memo` and receives empty props `{}` in both renders. The shallow comparison passes, so React **bypasses rendering `B` and its child `C**`.
5. **`D`** is a direct child of `App` and is not memoized $\rightarrow$ logs **`"D"`**.
