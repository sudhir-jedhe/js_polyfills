```js
// This is a React Quiz from BFE.dev

import * as React from 'react'
import { useState, useEffect } from 'react'
import { createRoot } from 'react-dom/client'

function App() {
  const [state1, setState1] = useState(1);

  const [state2] = useState(() => {
    console.log(2);
    return 2;
  });

  console.log(state1);

  useEffect(() => {
    setState1(3);
  }, []);

  return null;
}

const root = createRoot(document.getElementById("root"));
root.render(<App />);
    ```

### Step-by-Step Breakdown

**1. Initial Render (`state1 = 1`)**

* `useState(() => { console.log(2); return 2; })` passes a lazy initialization function to `useState`. This initializer runs **only on initial mount**, logging **`2`**.
* `console.log(state1)` runs and logs **`1`**.
* `useEffect` is queued to run after the render commits.

**2. Effect Phase (Mount)**

* The `useEffect` callback runs and triggers `setState1(3)`.

**3. Re-render (`state1 = 3`)**

* `App` re-renders.
* Lazy initial state functions are ignored on re-renders, so the function returning `2` is **not** called again.
* `console.log(state1)` runs with the updated state and logs **`3`**.
