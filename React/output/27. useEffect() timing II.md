*** copy 27. useEffect() timing II.md ***

```js
'infiniteLoopProtection:false'

import * as React from "react";
import { useState, useEffect} from "react";
import { createRoot } from "react-dom/client";

function App() {
  const [state] = useState(0)
  console.log(1)
  
  const start = Date.now()
  while (Date.now() - start < 50) {
    window.timestamp = Date.now()
  }
  
  useEffect(() => {
    console.log(2)
  }, [state])

  Promise.resolve().then(() => console.log(3))

  setTimeout(() => console.log(4), 0)

  return null
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)

```

### Step-by-Step Breakdown

**1. Synchronous Render Phase**

* `App` begins rendering synchronously:
* `console.log(1)` executes and logs **`1`**.
* The `while` loop blocks the main thread synchronously for $50\text{ ms}$.
* `useEffect` registers the passive effect callback (`console.log(2)`).
* `Promise.resolve().then(...)` schedules `console.log(3)` on the **Microtask Queue**.
* `setTimeout(..., 0)` registers `console.log(4)` on the **Macrotask Queue** (Timer task).
* `App` returns `null` and finishes its render/commit phase.

**2. Microtask Queue Phase**

* As soon as the synchronous execution stack finishes, the JavaScript engine drains the microtask queue before handling any new tasks:
* The Promise callback executes and logs **`3`**.

**3. Passive Effects Phase (React Scheduler / Task Queue)**

* React flushes passive effects (`useEffect`) via its internal scheduler (using `MessageChannel`), which runs before standard timer macrotasks:
* The `useEffect` callback executes and logs **`2`**.

**4. Macrotask Queue Phase**

* The event loop processes the next macrotask:
* The `setTimeout` callback executes and logs **`4`**.
