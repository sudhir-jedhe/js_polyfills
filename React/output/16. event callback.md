```js
// This is a React Quiz from BFE.dev

import * as React from 'react'
import { useState } from 'react'
import { createRoot } from 'react-dom/client'
import { screen, fireEvent } from '@testing-library/dom'

function App() {
  const [state, setState] = useState(0)
  const onClick = () => {
    console.log('handler')
    setState(state => state + 1)
    console.log('handler ' + state)
  }
  console.log('render ' + state)
  return <div>
    <button onClick={onClick}>click me</button>
  </div>
}


const root = createRoot(document.getElementById("root"));
root.render(<App />);

(async function () {
  const action = await screen.findByText('click me')
  fireEvent.click(action);
})()
    ```

### Step-by-Step Breakdown

**1. Initial Render (`state = 0`)**

* `App` initializes `state` to `0`.
* `console.log('render ' + state)` runs during render and logs **`"render 0"`**.

**2. Button Click Handler**

* When the button is clicked, `onClick` executes:
* `console.log('handler')` logs **`"handler"`**.
* `setState(state => state + 1)` schedules a state update to `1`. State updates are asynchronous and do not mutate the current scope's variable.
* `console.log('handler ' + state)` reads `state` from the current function closure (`0`) and logs **`"handler 0"`**.

**3. Re-render (`state = 1`)**

* React processes the scheduled state update and re-renders `App` with `state = 1`.
* `console.log('render ' + state)` executes with the new state value and logs **`"render 1"`**.
