***  29. useEffect() timing IV.md ***

```js
'infiniteLoopProtection:false'

import * as React from 'react'
import { useState, useEffect, useLayoutEffect} from 'react'
import { createRoot } from 'react-dom'

function App() {
  const [state, setState] = useState(0)
  console.log(1)
  
  const start = Date.now()
  while (Date.now() - start < 50) {
    window.timestamp = Date.now()
  }
  
  useEffect(() => {
    console.log(2)
  }, [state])

  Promise.resolve().then(() => console.log(3))

  setTimeout(() => console.log(4), 0)

  useLayoutEffect(() => {
    console.log(5)
    setState(state => state + 1)
  }, [])

  return null
}

const root = createRoot(document.getElementById('root'));
root.render(<App/>)

```

### Step-by-Step Breakdown

**1. Initial Render (`state = 0`)**

* `console.log(1)` logs **`1`**.
* The `while` loop blocks the main thread synchronously for $50\text{ ms}$.
* Hooks and async tasks are registered:
* `useEffect` is queued.
* Microtask 1 (`Promise.then`) is queued.
* Macrotask 1 (`setTimeout`) is queued.

**2. Layout Effect Phase**

* React synchronously runs layout effects immediately after the DOM mutation:
* `console.log(5)` logs **`5`**.
* `setState(state => state + 1)` is called inside `useLayoutEffect`. In React, state updates inside layout effects trigger a **synchronous re-render** before the browser paints and before passive effects or microtasks run.

**3. Synchronous Re-render (`state = 1`)**

* `console.log(1)` logs **`1`**.
* The `while` loop blocks synchronously for another $50\text{ ms}$.
* Microtask 2 (`Promise.then`) is queued.
* Macrotask 2 (`setTimeout`) is queued.
* `useLayoutEffect` has dependency array `[]`, so it does not run again.

**4. Microtask Queue Phase**

* As the synchronous execution finishes, the JavaScript engine drains the microtask queue in order:
* Microtask 1 executes and logs **`3`**.
* Microtask 2 executes and logs **`3`**.

**5. Passive Effects Phase (React Scheduler)**

* Because the layout effect triggered a synchronous re-render before passive effects were flushed, React flushes the passive effect for the latest committed state (`state = 1`):
* `useEffect` runs and logs **`2`**.

**6. Macrotask Queue Phase**

* The event loop processes the pending timer callbacks:
* Macrotask 1 executes and logs **`4`**.
* Macrotask 2 executes and logs **`4`**.
