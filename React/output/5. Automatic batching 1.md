```js
// This is a React Quiz from BFE.dev 

import * as React from 'react'
import { useState } from 'react'
import { createRoot } from 'react-dom/client'
import { screen, fireEvent } from '@testing-library/dom'

function App() {
  const [state, setState] = useState(0)
  console.log("App " + state)
  return (
    <div>
      <button onClick={() => {
        setState(count => count + 1)
        setState(count => count * 2)
      }}>click me</button>
    </div>
  )
}

(async () => {
  const root = createRoot(document.getElementById('root'));
  root.render(<App/>)

  fireEvent.click(await screen.findByText('click me'))
})()

    
    ```



```text
"App 0"
"App 2"

```

### Step-by-Step Breakdown

**1. Initial Render**

* The component initializes `state` with `0`.
* `console.log("App " + state)` executes and logs **`"App 0"`**.

**2. Click Event & State Updates**

* When the button is clicked, both updater functions are queued into React's update batch:

1. `count => count + 1` receives `0` and evaluates to `1`.
2. `count => count * 2` receives `1` and evaluates to `2`.

* React automatically batches these updates and schedules a single re-render with the final computed state of `2`.

**3. Re-render**

* `App` re-renders with `state = 2`.
* `console.log("App " + state)` executes and logs **`"App 2"`**.
