# What is React component

A **React component** is an independent, reusable piece of UI that encapsulates structure (HTML/JSX), style, and logic (JavaScript). Javascript function that retun JSX Markup. In React, an entire application is built like a tree of nested components.
React component names must always start with a capital letter, while HTML tags must be lowercase
---

## Core Types of Components

* **Function Components (Modern Standard):** Plain JavaScript functions that accept `props` (inputs) and return JSX (UI markup). They use React Hooks (like `useState`, `useEffect`) to manage state and side effects.
* **Class Components (Legacy):** ES6 classes extending `React.Component` with a `render()` method. Largely superseded by function components with hooks.

---

### Basic Example

```jsx
// A reusable Button component
function ActionButton({ label, onClick }) {
  return (
    <button onClick={onClick} className="btn-primary">
      {label}
    </button>
  );
}

// Parent component using ActionButton
function App() {
  const handleClick = () => alert("Clicked!");

  return (
    <div>
      <h1>Welcome</h1>
      <ActionButton label="Click Me" onClick={handleClick} />
    </div>
  );
}

```

---

### Key Characteristics

* **Reusability:** Write once and render multiple times with different data.
* **Props (Inputs):** Read-only data passed from parent components to customize behavior and appearance.
* **State (Internal Memory):** Private, dynamic data managed inside the component that triggers a re-render when updated.
* **Composability:** Complex interfaces are created by assembling smaller, simpler components together.
