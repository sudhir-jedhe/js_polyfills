The core distinction lies in the **single source of truth** for form data: **controlled components** keep data in React state, while **uncontrolled components** let the browser DOM manage its own internal state.

---

**Controlled Components**

Form input values are driven directly by React state via the `value` prop, and updates occur explicitly through change event handlers like `onChange`.

```jsx
function ControlledInput() {
  const [value, setValue] = useState('');

  return (
    <input 
      type="text" 
      value={value} 
      onChange={(e) => setValue(e.target.value)} 
    />
  );
}

```

* **Data flow:** User types $\rightarrow$ `onChange` fires $\rightarrow$ `setValue()` updates state $\rightarrow$ Component re-renders $\rightarrow$ DOM reflects new `value`.
* **Key advantages:** Instant field validation, dynamic disabled/enabled states, conditional formatting, and synchronized form fields.

---

**Uncontrolled Components**

Form elements retain their own internal state in the DOM. Values are read on demand (typically on form submission) using a React `ref` or native `FormData`.

```jsx
function UncontrolledInput() {
  const inputRef = useRef(null);

  const handleSubmit = (e) => {
    e.preventDefault();
    console.log(inputRef.current.value); // Pull value on submit
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="text" defaultValue="Initial" ref={inputRef} />
      <button type="submit">Submit</button>
    </form>
  );
}

```

* **Data flow:** User types $\rightarrow$ DOM updates directly $\rightarrow$ Value is queried when explicitly requested.
* **Key advantages:** Minimal re-renders on keystrokes, less boilerplate for simple forms, and easier integration with non-React UI libraries or native `<input type="file" />`.

---

**Feature Comparison**

| Feature                                 | Controlled                             | Uncontrolled                            |
| --------------------------------------- | -------------------------------------- | --------------------------------------- |
| **Source of Truth**                     | React Component State                  | Browser DOM Node                        |
| **Value Access**                        | Always available in state              | Read via `ref` or `FormData` on demand  |
| **Initial Value Prop**                  | `value`                                | `defaultValue` / `defaultChecked`       |
| **Re-render Cost**                      | Re-renders on every keystroke/change   | Zero re-renders during typing           |
| **Validation Capability**               | Real-time, character-by-character      | Submit-time validation                  |
| **File Inputs (`<input type="file">`)** | Not fully supported (read-only in DOM) | Standard approach (always uncontrolled) |

---

**Verdict**

Use **controlled components** when forms require real-time validation, dynamic input masking, or interdependent field logic. Use **uncontrolled components** for simple static forms, massive high-throughput forms (e.g., table grids with hundreds of inputs), or file uploads.
