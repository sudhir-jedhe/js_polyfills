Use **`useCallback` to cache a function definition** between renders, and **`useMemo` to cache the result of a calculation (a computed value)**.

---

**1. `useCallback` (Memoize Functions)**

Caches the function reference across renders. It only returns a new function instance if one of its dependencies changes.

* **Primary Use Cases:**
* Passing callback props to child components optimized with `React.memo`.
* Passing functions into the dependency array of other hooks (like `useEffect`).
* Custom hook functions returned to consumers.

```jsx
// Caches the function itself
const handleSearch = useCallback((query) => {
  fetchResults(query, filter);
}, [filter]); // Only recreated if `filter` changes

```

---

**2. `useMemo` (Memoize Computed Values)**

Executes the function during rendering and caches its return value. It only recalculates the value if its dependencies change.

* **Primary Use Cases:**
* Skipping expensive, CPU-heavy calculations (e.g., sorting, filtering, or aggregating large arrays).
* Preserving referential identity for objects or arrays passed to memoized children or hook dependencies.

```jsx
// Caches the RETURN VALUE of the calculation
const visibleTodos = useMemo(() => {
  return todos.filter(t => t.status === filter).sort(sortByDate);
}, [todos, filter]); // Only recomputed if `todos` or `filter` changes

```

---

**Direct Comparison**

| Feature               | `useCallback(fn, deps)`                              | `useMemo(() => fn, deps)`                                      |
| --------------------- | ---------------------------------------------------- | -------------------------------------------------------------- |
| **What it caches**    | The function definition itself                       | The calculated return value                                    |
| **Execution**         | Returns the function uncalled                        | Calls the function during render to get the result             |
| **Equivalent syntax** | `useCallback(fn, deps)`                              | `useMemo(() => () => fn(), deps)` (if returning a fn)          |
| **Main purpose**      | Prevent handler recreation & broken prop comparisons | Prevent repeated expensive operations & object reference churn |

---

**When NOT to Use Either**

Do not wrap every function or calculation in these hooks. Memoization introduces overhead (memory for caches and dependency checks on every render).

* **Skip if:** The calculation is lightweight (e.g., basic arithmetic, simple string concat, small array mapping).
* **Skip if:** The child component receiving the function/object is not wrapped in `React.memo`.
